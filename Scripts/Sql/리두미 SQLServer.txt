기본 세팅 방법.
	1. SQLServer 2022 설치
	2. SSMS 도 알아서 설치 (자동인진 모름 깐지 오래됨.)
	3. 아래 내용들 정독

-----------------------------------------------------------
SQL 인증 방식 사용 방법
	1. SSMS 실행 -> Windows 인증 로그인
	2. 연결 우클릭 -> 속성 -> 보안 -> SQLServer인증 / Windows 인증 혼합 모드 사용 체크
	3. 아래 SQL 실행해서 sq 계정 비번 1234로 변경
GO
ALTER LOGIN sa ENABLE;
GO
ALTER LOGIN sa WITH PASSWORD = '1234';
GO

	

-----------------------------------------------------------
서비스 포트 확인/변경
SQL Server 2022 Configuration Manager 실행
	1. SQL Server Network Configuration 아래쪽의 Protocols for MSSQLServer 클릭 -> TCP/IP 선택 후 확인 변경가능



-----------------------------------------------------------
IP 포트 사용하여 접속 방법
기본적으로 1433 포트 사용하기 때문에 포트를 명시하지 않아도 되긴함.

서버 이름(S): 127.0.0.1,1433과 
인증(A): SQL Server 인증
	로그인(L): sa
	암호(P): 1234

와 같이 입력해서 접속하면 됨.


-----------------------------------------------------------
똥컴 SQLServer 메모리 최적화

메모리는 서버 우클릭(트리 최상위 노드) -> 속성 -> 메모리 -> 2048MB로 바꿔서 쓰니까 쓸만함. 
512MB 하니까 메모리 부족으로 제대로 수행이 안됨.
