# 2026-08-01-libSpine-빌드속도-개선

## 완료 사항
- 파일: `ThirdParty\Cocos2d-x\cocos\editor-support\spine\proj.win32\libSpine.vcxproj`
- 원인 1 (PCH 없음) 수정:
  - `precheader.cpp`(cocos\precheader.cpp, cocos2d.h PCH)를 Create 항목으로 추가
  - 4개 설정(Debug/Release × Win32/x64) ClCompile에 `PrecompiledHeader=Use`, `PrecompiledHeaderFile=precheader.h`, `ForcedIncludeFiles=precheader.h`, `CompileAs=CompileAsCpp` 추가
  - `.c` 파일은 libcocos2d.vcxproj의 md5.c/xxhash.c 패턴과 동일하게 C++로 컴파일 (spine 헤더에 extern "C" 가드 있어 링크 안전)
- 원인 2 (/MP 없음) 수정:
  - `Debug|x64` / `Release|x64`에 `MultiProcessorCompilation=true` 추가
  - (기존에 없던 `Release|Win32`에도 동일하게 추가됨)

## 검증 결과
- libSpine Debug|x64, Release|x64, Debug|Win32 모두 빌드 성공
- Debug|Win32에서 기존 C 코드의 C4018 signed/unsigned 경고만 발생 (기존 C++ 컴파일과 동일한 수준, 오류 아님)
- 출력: `ThirdParty\Cocos2d-x\Output\{Platform}\{Configuration}\libSpine.lib`

## 참고
- 전체 libcocos2d 빌드 (Scripts\Build-Cocos.bat)는 아직 미실행. 필요 시 실행
