## 조치 내역

### K4: 구조 개선 (sgf)

- **S1 공용 배치 렌더러**: `sgf/Graphics/BatchRenderer.h/.cpp` 신규 작성
  - 공통 흐름: `Initialize`(셰이더 컴파일 + CB 생성 + 파생 리소스), `Begin`(+`OnBegin` 훅), `End`(+순수 가상 `Flush`), `virtual Finalize`
  - 파생 훅: `ShaderSource()`, `VertexLayout()`, `CreateBatchResources()`, `OnBegin()` / protected: `m_pDevice`, `m_Shader`, `m_CbFrame`, `m_ViewProjection`, `m_bBegun`, 헬퍼 `ApplyFrameStates()`
  - `Project/sgf.vcxproj`에 등록
- **Renderer2D.h/.cpp**: `BatchRenderer` 상속으로 재구성 — 클래식 멤버/초기화 플로우 제거, 훅만 구현 (흰 텍스처, VB/IB, 상태 설정), Flush는 `ApplyFrameStates()` 사용
- **Renderer3D.h/.cpp**: 동일 상속 + **S3** `FlushBatch(VertexBuffer&, jc::Vector<VertexPC>&, TOPOLOGY)` 단일 헬퍼로 삼각형/선 배치 플러시 중복 제거
- **S2 | GraphicDevice**: private `BindWindowSurface(Window*)` / `BindBackBufferSurface()` 헬파 추가, `BeginFrame` 2종 + `SetRenderTarget(nullptr)` 양 분기를 헬파로 통일 (레거시 `BeginFrame(color)`에 FullViewport 적용 보강)
- **S4 | 네이밍 통일**: `SwapChain`(m_pSwapChain/m_pRenderTargetView/m_Width/m_Height), `DepthStencilSurface`(m_pDepthStencilView) — `접미사 _` → `m_` prefix (코드베이스 다수 관례 채택)
- **S5 | SgfMath 가드**: `PerspectiveFovLH`(`_nearZ<=0`/`_farZ<=_nearZ`/`_aspect<=0`/`_fovY<=0||>=Pi_v`)와 `OrthographicOffCenterLH`(`_right<=_left`/`_top<=_bottom`/`_farZ<=_nearZ`)에 부정 입력 시 `Identity()` 반환 가드. 데드코드 제거는 **하지 않음** (sgfr이 `Lerp/SRT2D/RotationX~Y/TransformPoint` 등 사용 중이라 확인)

  - `TextureShaderSource()` — 11/12/19/22 공용 (NDC 통과 + UV 샘플)
  - `FillColorCube()` — 17/19/20 공용 (정점 8 + 인덱스 36)

  - 11: `TextureShaderSource` 제거 (Main은 Common 사용)
  - 12: 11_Function.h 의존 제거 → Common 직접 사용 (쉐이더 재사용 주석 반영)
  - 17: `RasterizerShaderSource`/`FillColorCube` 제거 → `ColorTransformShaderSource`
  - 19: `RtCubeShaderSource`/`RtQuadShaderSource`/`FillRtColorCube` 제거 → Common (`FillRt→FillColorCube`)
