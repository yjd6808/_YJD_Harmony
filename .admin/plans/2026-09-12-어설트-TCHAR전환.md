## 2. 설계 (D-1)

1. `Assert.h`: `_fmt`만 `const _char*`로 변경. 나머지 4개(`_expectStr`, `_filePath`,
   `_functionName`, `_lineNum`)는 narrow 유지 (`#expect`/`__FILE__`/`__FUNCTION__`이 narrow이므로).
   기본 메시지 → `_T("메시지 없음")`.
2. `Assert.cpp` 본문: 버퍼 `_char` + `StringUtilT::Length/FormatBuffer/ConcatInnerFront` +
   `_tprintf(_T(...))`. narrow 인자(`_expectStr`, 파일명, `_functionName`)는 `%hs`로 출력.
   박스 문자(`┌│└`)는 `_T()`화. `FileNameLevel`은 narrow 임시 버퍼 + narrow판 그대로 사용 후
   `%hs` 출력 (assert 경로에서 `String` 힙 할당·재귀 assert 위험 회피).
3. 호출부 리터럴 일괄 `_T()`화: `jc_assert_msg(..., "..."` → `jc_assert_msg(..., _T("..."`.
   `%s` 자리에 narrow 값(`typeid().name()`, `GetBinaryReadErrorMessage()`, narrow `Source` 등)이
   있으면 `%hs`로 개별 수정. 멀티라인 호출은 수동 처리.
4. 제1규칙 5항 준수 — 새 `const char*` 파라미터 없음.
