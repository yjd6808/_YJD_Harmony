# 2026-09-13 코루틴 명명 정리

## 배경
- `Coroutine.h`는 `pCallerCtx_`/`callerRegs_`로 절반 개명된 상태.
- `Coroutine.cpp`/`CoroutineImpl.asm`은 구명(`callerCtx_`/`schedRegs_`/`threadId_`/`_padId_`) 잔류.
- `static_assert(offsetof(CoContext, schedRegs_))`는 컴파일 불가 상태.
- `threadId_`는 쓰기만 있고 읽기가 전무(write-only). `coeWrongThread` 검사 코드 없음.

## 범위 (확정)
- 핵심 3종만: `Projects/jc/Sources/jc/Threading/Coroutine.h`, `Coroutine.cpp`, `CoroutineImpl.asm`
- `CoDesc`/`CoStackSpec` `_` 접미사 개명은 다음 단계로 연기 (호출처 10+ 파일 파급)
- `coeWrongThread` enum + `CoErrorString` case 삭제
- 패딩 통일: `_pad*` → `pad*_` (C++ `CoRegs`/`CoContext` + asm `CoStack`/`CoRegs`/`CoContext`)

## threadId_ 삭제 근거
- 읽기처 0건. `InitCtx`(0 대입), `CoRun`/`CoAllocCtx`(`GetCurrentThreadId()` 대입)만 존재.
- `coeWrongThread`를 반환/검사하는 코드 없음. `CoLookupResumable`은 id 맵 조회로 타 스레드 차단 (stale 보고).
- `CoMgr` 자체가 `thread_local`이라 코루틴은 생성 스레드에 귀속. 별도 저장 불필요.
- 필요 시 `Thread::GetThreadId()` (TLS 캐시)로 대체 가능.

## 변경 목록
1. `Coroutine.h`
   - `coeWrongThread` enum 삭제
   - `CoRegs`: `_padFp_` → `padFp_`, `_padAlign_` → `padAlign_`
   - `CoContext`: `_padCancel_` → `padCancel_`
   - `static_assert schedRegs_` → `callerRegs_` (2건)
   - `CoYield()` 인라인: `callerCtx_` → `pCallerCtx_`, `schedRegs_` → `callerRegs_`
2. `Coroutine.cpp`
   - `CoErrorString`의 `coeWrongThread` case 삭제
   - `InitCtx`: `threadId_` 대입 삭제, `schedRegs_` → `callerRegs_`, `callerCtx_` → `pCallerCtx_`
   - `CoResume` x2, `CoRun`, `CoEntry`, 주석: `callerCtx_`/`schedRegs_` 개명
   - `CoRun`, `CoAllocCtx`: `threadId_ = GetCurrentThreadId()` 삭제
3. `CoroutineImpl.asm`
   - `CoStack`: `_pad0_/_pad1_/_pad2_` → `pad0_/pad1_/pad2_`
   - `CoRegs`: `_padFp_` → `padFp_`, `_padAlign_` → `padAlign_`
   - `CoContext`: `threadId_+_padId_` (2xDWORD) → `pad0_` (QWORD), `callerCtx_` → `pCallerCtx_`, `schedRegs_` → `callerRegs_`, `_pad0_` → `pad1_`, `_padCancel_` → `padCancel_`
   - `OFFSET_COCTX_THREADID` 삭제, `OFFSET_COCTX_CALLER/SCHEDREGS` 갱신
