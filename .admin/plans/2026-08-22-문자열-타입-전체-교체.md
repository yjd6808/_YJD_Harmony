## 2. 설계

- jc::String은 UTF-8 narrow. 모든 파일 경로/이름은 UTF-8로 통일.
- wchar 경로는 내부에서 Utf8ToWide 변환 후 Win32 API 호출 (Window와 동일 패턴).
- 셰이더 소스 literal은 `jc::String`으로 감싸거나, `const char*` 유지 후 내부에서 String으로 변환 — 성능상 literal 유지가 유리하나, 요청상 전체 교체이므로 `const jc::String&` 파라미터로 받는 경우 호출부에서 literal → String 암시적 변환 활용.
- `ShaderSource()` 반환은 `const jc::String&` 또는 `jc::String`으로 변경 시 정적 String 변수 필요 — 추후 결정.
