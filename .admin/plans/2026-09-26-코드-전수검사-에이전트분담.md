# 코드 전수검사 (에이전트 분담)

## 방식

- 스크립트 사용 금지. Read 도구로 파일을 직접 하나하나 열어 육안 검사.
- 파일 30개당 에이전트 1개. 총 18개 영역.
- 수정 금지. 위반 목록 보고만 한다.

## 영역

- jc 10개: A1 루트A-M, A2 루트N-Z+Allocator+Encoding+Pattern+Debug+Utils/Console,
  A3 Container(수집/해시/리스트/CMessage), A4 Container(Property/연산자),
  A5 Sync+Tree/Vector, A6 Threading+Pool, A7 IO(루트+File+Memory+Engine),
  A8 IO/Http+Logger+Utils(비Console), A9 Primitives, A10 _Extern+TypeTraits+Wrapper+Natvis+PCH
- sgf 4개: B1 Graphics(전반), B2 Graphics(후반), B3 Scene, B4 Core+Audio+Input+PCH
- sgfr 4개: C1 Tutorial 01-09, C2 Tutorial 10-19, C3 Tutorial 20-34, C4 Practice+Common+기타

## 검사 기준

`.opencode/rules/coding-conventions_cpp.md` 전체 (신규 구분자/설명 규칙 포함).
