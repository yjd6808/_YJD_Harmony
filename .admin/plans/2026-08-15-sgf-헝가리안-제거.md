## 변경 내용

### 치환 규칙 (계획서와 동일)

- 멤버: `b<Name>_` → `<name>_` (예: `bVsync_` → `vsync_`, `b2D_` → `is2D_`)
- 로컬: `b<Name>` → `<name>` (예: `bNeedUninit` → `needUninit`)
- 파라미터: `_b<Name>` → `_<name>` (예: `_bEnable` → `_enable`)

### 적용 토큰 (총 28종)

- 멤버 21종: b2D_, bInitialized_, bComInitialized_, bPaused_, bLoop_, bVsync_, bClosed_, bHasSurface_, bBegun_, bDynamic_, bWireframe_, bConstantsDirty_, bIndexed_, bDepthOnly_, bVisible_, bKeyDown_, bPrevKeyDown_, bMouseDown_, bPrevMouseDown_
- 파라미터 6종: _bDynamic, _bVsync, _bEnable, _bLoop, _bWireframe, _bActive
- 로컬 6종: bFirstPress, bFound, bNeedUninit, bResult, bHasFmt, bHasData

### 후속 발견 사항 (계획서 누락분, 최종 스캔에서 확인)

- **스캔 마스크 순서 버그**: `//` 주석 마스킹이 문자열 마스킹보다 뒤에 있어, 큰따옴표(`\"`)가 포함된 `//` 주석 이후 영역이 스캔에서 제외되던 문제 발견
  - 이에 숨겨져 있던 `bHasFmt`/`bHasData`(SoundEngine.cpp)와 `_bActive`(Application.cpp) 3종이 1차 완료 후 잔존
  - 마스크 순서를 raw → `//` 주석 → 블록 주석 → 문자열 로 수정한 뒤 재스캔하여 모두 제거
- 치환은 raw 텍스트 직접 적용 방식으로 변경 (주석 내 언급까지 일관 갱신, 위치 보존)

### 유지 대상 (변경 없음)

- `p`/`_p` 포인터 접두, `_sz`/`s_sz*` 문자열, `sAddQuad` (static 접두)
- `nChannels`/`nSamplesPerSec`/`nBlockAlign`/`nAvgBytesPerSec` (WAVEFORMATEX SDK 필드)

### 인코딩

- 치환 과정에서 모든 변경 파일을 UTF8 BOM + CRLF 로 통일 저장 (계획 K2 충족)
