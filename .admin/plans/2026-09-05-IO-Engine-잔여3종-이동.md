# IO Engine 잔여 3종 이동 계획 (IODaemon.h/.cpp, IOTypes.h → Engine/)

## 목표
- `Sources/jc/IO/` 루트에 남은 `IODaemon.h`, `IODaemon.cpp`, `IOTypes.h`를
  `Sources/jc/IO/Engine/`으로 이동한다. (엔진 귀속 3종, 루트 잔류 0)
- 논리 include 경로를 `jc/IO/X.h` → `jc/IO/Engine/X.h`로 갱신한다.
- 이동 과정에서 발견된 `IODaemon.h` 중복 include 1건을 제거한다.

## 현상
- `IODaemon.h:19`와 `:21`에 `#include "jc/IO/IOTypes.h"` 중복 존재 (pragma once라 무해하나 정리 대상).
- `IODaemon.cpp:1`은 자기 헤더를 구 경로로 include.

- 이동 3종: `IODaemon.h`, `IODaemon.cpp`, `IOTypes.h` (git mv 상당: 삭제+생성)
