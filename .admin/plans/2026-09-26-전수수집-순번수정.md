# 전수수집 + 순번수정

## 방식

1. 18개 영역 병렬 수집 (에이전트, 읽기 전용, 스크립트 금지).
2. 수집 결과를 규칙별 섹션으로 분류하고 1~N 순번 부여.
3. 내가 직접 1번부터 순차 수정.
4. 소규모 섹션: 파일명+위치+수정내용 단위로 처리.
5. 대규모 섹션: 섹션 단위마다 빌드 후 오류 수정.

## 영역 (기존과 동일)

- jc 10개: A1 루트A-M, A2 루트N-Z+Allocator+Encoding+Pattern+Debug+Utils/Console,
  A3 Container 수집계, A4 Container Property, A5 Sync+Tree/Vector,
  A6 Threading+Pool, A7 IO 핵심, A8 IO/Http+Logger+Utils, A9 Primitives,
  A10 _Extern+TypeTraits+Wrapper+Natvis+PCH
- sgf 4개: B1/B2 Graphics, B3 Scene, B4 Core+Audio+Input+PCH
- sgfr 4개: C1 Tutorial 01-09, C2 10-19, C3 20-34, C4 Practice+Common+기타

## 기준

`.opencode/rules/coding-conventions_cpp.md` 전체. 구분자는 직전 작업으로 정리됨.
