# 벡터 Mul 통합

## 목표
- vec2/vec3/vec4에 mat4 곱셈(Mul)을 정본으로 둔다.
- mat4::TransformPoint/TransformVector/Transform은 vec::Mul에 위임한다.
- 호출자가 w(1=점, 0=방향)를 직접 지정해 학습 효과를 유지한다.

## 변경 파일
- Projects/jc/Sources/jc/Math.h (1개)

## 순서
1. vec2::Mul에 const 추가, 주석 보강
2. vec3::Mul(mat, w), vec4::Mul(mat) 선언 추가
3. mat4::Transform* 본문을 Mul 위임으로 교체
4. mat4 정의 이후에 vec Mul 본문 inline 정의
5. jc 빌드 검증 (Scripts\BuildProject\jc.bat -C Debug -P x64)
