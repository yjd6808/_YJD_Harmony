# 컬링·감기 불일치 수정 계획 (수정전/수정후)

## 1. 목표
- 디폴트 `cmBack + ffClockwise`를 전제로 sgf의 컬링·감기 불일치를 수정한다.
- 2D는 상태 고정(`cmNone`)으로, 3D 팩토리 메시는 감기 수정으로 해결한다.
- 손대지 않는 범위도 명시한다.

## 2. 배경 (감사 결과 요약)
- `Renderer2D`는 래스터라이저를 한 번도 세팅하지 않는다. 배치 출력이 전역 잔류 상태에 좌우된다.
- 엔진 내장 2D 지오메트리(PushQuad 계열·Circle/Line 팬)는 화면 기준 반시계 → `cmBack`에서 전멸한다.
- `Mesh::Cube/Sphere/Capsule/Cylinder캡`은 inside-out (수치 하네스 + Tutorial 13 앵커로 확정).
- 멀쩡한 것: `Mesh::Plane/Quad3D/Rect2D`, `Cylinder` 옆면, `Renderer3D::DrawCube`, Tutorial 수제 지오메트리, 선/점.

## 3. 수정 1 — Renderer2D::OnBegin (Graphics/Renderer2D.cpp:157-166)

수정전:

```cpp
	pDevice_->Context().SetDepth(DepthMode::dmDisabled);
	pDevice_->Context().SetBlend(BlendMode::bmAlpha);
}
```

수정후:

```cpp
	pDevice_->Context().SetDepth(DepthMode::dmDisabled);
	pDevice_->Context().SetBlend(BlendMode::bmAlpha);
	pDevice_->Context().SetRasterizer(CullMode::cmNone, FillMode::fmSolid);
}
```

## 4. 수정 2 — Renderer2D::Flush (Graphics/Renderer2D.cpp:546-547)

수정전:

```cpp
	pDevice_->Context().SetDepth(DepthMode::dmDisabled);
	pDevice_->Context().SetBlend(BlendMode::bmAlpha);
```

수정후:

```cpp
	pDevice_->Context().SetDepth(DepthMode::dmDisabled);
	pDevice_->Context().SetBlend(BlendMode::bmAlpha);
	pDevice_->Context().SetRasterizer(CullMode::cmNone, FillMode::fmSolid);
```

- OnBegin만으로는 `DrawMesh`→머티리얼 바인딩 잔재가 배치에 누수되므로 Flush 직전 확정이 함께 필요하다.
- 2D에 `cmBack`을 걸어도 버려질 뒷면이 없어 절감이 없고, 반전 스케일과 충돌하므로 `cmNone`이 정답이다.

## 5. 수정 3 — 디폴트 2D 머티리얼 (Graphics/ResourceMgr.cpp:583-585)

수정전:

```cpp
	if (!pMat2D->Initialize(pDevice_)
		|| !pMat2D->SetBlend(BlendMode::bmAlpha)
		|| !pMat2D->SetDepth(DepthMode::dmDisabled))
```

수정후:

```cpp
	if (!pMat2D->Initialize(pDevice_)
		|| !pMat2D->SetBlend(BlendMode::bmAlpha)
		|| !pMat2D->SetRasterizer(CullMode::cmNone)
		|| !pMat2D->SetDepth(DepthMode::dmDisabled))
```

- `DrawMesh` 경로에서 `Material::Bind`가 `cmBack`을 덮어쓰는 것을 막는다.
- 디폴트 3D 머티리얼은 `cmBack` 유지 (수정 없음).

## 6. 수정 4 — Renderer3D::BeginScene (Graphics/Renderer3D.cpp:116-124) [필수]

수정전:

```cpp
	GraphicContext& context = pDevice_->Context();

	frameCb_.Update(pDevice_->Context(), _frame);
```

수정후:

```cpp
	GraphicContext& context = pDevice_->Context();

	context.SetRasterizer(CullMode::cmBack, FillMode::fmSolid);

	frameCb_.Update(pDevice_->Context(), _frame);
```

- 선택이 아니라 필수다. 컨텍스트가 전역 1개라 2D의 `cmNone`이 3D로 누수된다 (특히 멀티윈도우 순회).
- 3D 배치는 상태를 스스로 선언하지 않으므로 진입점 명시가 유일한 차단 위치다.

## 7. 수정 5 — Mesh::Cube 6면 (Graphics/Mesh.cpp:184-194)

수정전 (전 면 동일 패턴):

```cpp
		indices[face * 6 + 0] = base + 0;
		indices[face * 6 + 1] = base + 1;
		indices[face * 6 + 2] = base + 2;
		indices[face * 6 + 3] = base + 0;
		indices[face * 6 + 4] = base + 2;
		indices[face * 6 + 5] = base + 3;
```

수정후 (삼각형마다 중·후 인덱스 교환 = 감기 반전):

```cpp
		indices[face * 6 + 0] = base + 0;
		indices[face * 6 + 1] = base + 2;
		indices[face * 6 + 2] = base + 1;
		indices[face * 6 + 3] = base + 0;
		indices[face * 6 + 4] = base + 3;
		indices[face * 6 + 5] = base + 2;
```

- 기준: `FillColorCube` 패턴 (`sgfr/Common/TutorialCommon.cpp:111-118`).
- 덤으로 `SetDebugName` 앞에 `format_ = VertexFormat::vfPNT3D;` 추가 (타 팩토리와 달리 누락됨).

## 8. 수정 6 — Sphere/Capsule 격자 (Graphics/Mesh.cpp:247-249, 403-404)

수정전:

```cpp
		indices.PushBack(v00); indices.PushBack(v10); indices.PushBack(v01);
		indices.PushBack(v01); indices.PushBack(v10); indices.PushBack(v11);
```

수정후:

```cpp
		indices.PushBack(v00); indices.PushBack(v01); indices.PushBack(v10);
		indices.PushBack(v01); indices.PushBack(v11); indices.PushBack(v10);
```

- Sphere와 Capsule 두 곳에 동일 적용 (동일 격자 패턴).

## 9. 수정 7 — Cylinder 캡 (Graphics/Mesh.cpp:309-322, 옆면 제외)

수정전:

```cpp
		indices.PushBack((_u32)0); indices.PushBack(v1); indices.PushBack(v0);
	...
		indices.PushBack((_u32)1); indices.PushBack(v0); indices.PushBack(v1);
```

수정후:

```cpp
		indices.PushBack((_u32)0); indices.PushBack(v0); indices.PushBack(v1);
	...
		indices.PushBack((_u32)1); indices.PushBack(v1); indices.PushBack(v0);
```

- 옆면(`Mesh.cpp:299-308`)은 앞면으로 정상이므로 수정하지 않는다.

## 10. 수정 8 — Mesh::Triangle2D (Graphics/Mesh.cpp:96-106)

수정전:

```cpp
// 단위 삼각형. 중심이 원점, 시계 반대 방향(앞면) 감기. (VertexPTC)
	PrimitiveBuilder::BuildTriangle(pTop, pBottomLeft, pBottomRight, color::WHITE, result);
```

수정후:

```cpp
// 단위 삼각형. 중심이 원점, 시계 방향(앞면) 감기. (VertexPTC)
	PrimitiveBuilder::BuildTriangle(pTop, pBottomRight, pBottomLeft, color::WHITE, result);
```

- `Rect2D`와 감기를 통일한다. 2D 경로는 수정 1·2로 `cmNone`이라 당장 보이지만, 사용자 `cmBack` 머티리얼에서도 살아남도록 맞춤.

## 11. 수정하지 않는 것

- `PushQuad` 계열 감기: 수정 1·2의 `cmNone` 전제에서 무의미. 손대지 않음.
- Tutorial 수제 지오메트리·`FillColorCube`·`DrawCube`: 이미 앞면.
- `Mesh::Plane/Quad3D/Rect2D`, `Cylinder` 옆면: 이미 앞면.
- 디폴트 3D 머티리얼·`GraphicDevice` 초기화 61행: `cmBack` 유지.
- 선/점(`DrawLine3D/Grid/Axis`): 컬링 면역.
