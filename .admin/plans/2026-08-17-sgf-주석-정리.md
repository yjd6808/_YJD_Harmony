# sgf 주석 정리 플랜 (2026-08-17)

## 목표

sgf 프로젝트(`UltimateHarmony/Projects/sgf/Sources/sgf`)의 주석 형식을 통일한다.

1. `// === X ===` 데코레이션 주석 제거
   - `////` 90자 구분선 + `// 제목` 블록으로 교체
   - 구분선 길이: `90 - (들여쓰기 레벨 × 4)` (코딩 컨벤션 함수 구분자 규칙 동일)
   - **구분선 이후 소스코드 사이 빈 줄 금지** (제목 바로 아래 코드)
   - 구분선 이전 빈 줄은 유지 (섹션 구분)
2. 기존 `=` 구분선 블록(Buffers.cpp / GraphicsEnums.h / Renderer2D.cpp) → `/` 스타일로 통일
3. PipelineState.cpp: 구분선 길이 53→90 통일, 구분선 뒤 빈 줄 제거
4. trailing 주석 컬럼 정렬 (들여쓰기 불일치 수정)
   - 연속된 선언 그룹에서 주석을 같은 컬럼으로 정렬 (최장 코드 + 1탭 → 탭 스톱)
   - 코드 길이 80자 초과 라인은 단일 탭 유지
   - 스페이스 정렬 → 탭 정렬 통일
5. 파일 헤더 `* =====` 와 .cpp 함수 `/` 구분자(이미 90자)는 컨벤션 규칙이므로 유지
