# Practice 04 3D 렌더링 파이프라인 완성 계획

- 날짜: 2026-10-17
- 대상: `Projects/sgfr/Sources/sgfr/Practice/04_3DPipelinePractice/` (CPU/GPU 2개 파일)

## 1. 배경 및 목적
- `02_3DPipelineTemplate`(3D 템플릿)을 복사하고 `03_2DPipelinePractice`(CPU/GPU 정점 굽기)의 구조를 따라 만든 `04_3DPipelinePractice`가 이름만 3D로 바뀐 채 2D 코드(직교 투영, vec2 좌표, 2축 회전)가 그대로 남아 있다.
- 원근 투영 행렬을 직접 작성하고, 3D 카메라(LookAt 뷰 행렬), 3D 큐브 정점/인덱스, 깊이 테스트까지 완성한다.
- 주석은 2D 버전(`03_2DPipelinePractice/CPUTransformedVertex.cpp`)의 수학 설명 스타일을 따른다.

## 2. 기존 코드 현황 (사전 분석)
- `CPUTransformedVertex3D.cpp`
  - 모델 구조체 이름이 `s2DModel`이고, `UpdateTransform`이 `RotationZ(z) * RotationX(y) * RotationX(x)`로 y축 회전에 `RotationX`를 잘못 사용.
  - `mat4 matWorld_;` 옆 `// camera world` 잘못된 주석.
  - `s3DCamera`에 LookAt 방식 View 행렬은 이미 구현되어 있으나 `up_` 기본값이 없고 `targetPos_`/`localRotation_`이 미사용 상태.
  - Main의 투영이 2D 직교 투영이고 정점/좌표가 2D 그대로.
  - CPU 정점 굽기가 `vec3::Mul`(w 무시)이라 원근 나눗셈 불가.
- `GPUTransformedVertex3D.cpp`
  - 셰이더는 3D용(`mul(float4(pos,1), mul(matWorld_, matVp_))`)으로 정상.
  - 모델/카메라 구조체가 `s2DModel`/`s2DCamera`(2D `UpdateView`), Main이 2D 직교 투영.
- 참조: `02_3DPipelineTemplate`(큐브 8정점/36인덱스, `LookAtLH` + `PerspectiveFovLH`, 깊이 `dmReadWrite`), `Tutorial/13_Cube3D`, `Docs/sgfr/02_Practice/projection-matrix.html`.

## 3. 구현 계획
1. 모델 구조체를 `s3DModel`로 정리: `localRotation_` 3축 회전을 `Scale * (RotationZ * RotationY * RotationX) * Translation` 순으로 수정, 잘못된 주석 제거, 큐브 정점 8개(vec3, z 명시) + 색 8개 + 인덱스 36개로 구성.
2. `s3DCamera` 정리: `localPos_`(eye) / `targetPos_` / `up_`(기본 `vec3::UP`), LookAt 방식 View 행렬 유지, 미사용 `localRotation_` 제거.
3. 원근 투영 행렬을 수동으로 작성하고 유도 주석 추가(닮은 삼각형 → NDC 정규화 → `w`에 `z` 저장). fovY 60도 / near 0.1 / far 100 / 화면 비율 적용.
4. Main을 3D로 완성: 카메라(eye `(0,0,-2.5)`, 원점 바라봄), 모델 큐브, 깊이 테스트 `dmReadWrite`.
5. CPU 경로는 `vec4::Mul(mat4)`로 클립 좌표를 구한 뒤 `w`로 나눠 NDC를 저장.
6. GPU 경로는 동일한 카메라/모델로 구성하고 상수버퍼(`matVp`/`matWorld`)로 전달.

### 조작키(3D)
- 방향키: 카메라 이동(eye와 target 동시 이동 = pan)
- `A`/`D`, `Q`/`E`, `W`/`S`: 모델 x / y / z 이동
- `F`/`G`: 모델 Y축 회전, `R`/`T`: 모델 X축 회전, `V`/`B`: 모델 Z축 회전
