# Practice 03 서브메뉴 분리 계획 (CPU/GPU 정점 굽기)

## 1. 목표
- `03. 2D 렌더링 파이프라인 연습` 진입 시 콘솔 서브메뉴(1. CPU 정점 굽기 / 2. GPU 정점 굽기 / 0. 뒤로가기)를 출력한다.
- 새 필터 없이 기존 필터(`02. Practice\03. 2D 렌더링 파이프라인 연습`)에 cpp만 추가하고 함수명으로 분리한다.
- 헤더 추가 없이 `extern` 선언으로 가져와 호출한다.
- GPU 파일 내부는 사용자가 직접 수정하므로 파일명(함수명) 수준만 맞춰 빌드가 통과하게 둔다.

## 2. 사전 분석 결과
- `03_2DPipelinePractice_Main.cpp`(273줄)는 현재 CPU 굽기 경로(`GetShaderSource_PreTransformed` + 매 프레임 CPU 행렬 계산·동적 VB 업로드)를 `Practice_2DPipelinePractice_Main()`에서 직접 실행한다.
- GPU용 셰이더(`GetShaderSource_Transformed`)는 같은 파일에 미완성 상태로 존재하며 호출되지 않는다.
- 메뉴 입력 패턴은 `sgfr/Main.cpp`의 `ReadSelection()`(`jc::Console::ReadLineBuffered` + `_stscanf_s`)을 그대로 따른다.
- `PracticeRegistry.cpp`는 `Practice_2DPipelinePractice_Main`만 참조하므로 수정 불필요.

## 3. 설계
- `03_2DPipelinePractice_Main.h` 유지 (`Practice_2DPipelinePractice_Main()` 선언).
- `03_2DPipelinePractice_Main.cpp` → 서브메뉴 루프로 교체. `extern void CPUTransformedVertex_Main();`, `extern void GPUTransformedVertex_Main();` 선언 후 번호로 분기한다.
- `01_CPUTransformedVertex.cpp` 신규. 기존 Main.cpp 본문을 그대로 이동하고 함수명만 `CPUTransformedVertex_Main()`으로 변경한다. (자기 헤더 include는 제거)
- `02_GPUTransformedVertex.cpp` 신규. 01 복사본에서 함수 정의명만 `GPUTransformedVertex_Main()`으로 교체한다. 나머지 코드는 사용자 수정 예정.
- `sgfr.vcxproj`, `sgfr.vcxproj.filters`에 `ClCompile` 2줄 추가. `Filter`는 기존 03 필터로 지정한다.

## 4. 파일 목록
- 수정: `Practice/03_2DPipelinePractice/03_2DPipelinePractice_Main.cpp`, `Project/sgfr.vcxproj`, `Project/sgfr.vcxproj.filters`.
- 신규: `Practice/03_2DPipelinePractice/CPUTransformedVertex.cpp`, `Practice/03_2DPipelinePractice/GPUTransformedVertex.cpp`. (최종명. 작업 중 `01_`/`02_` 접두어 제거됨)

## 6. 04번(3D) 동일 구성 추가
- `04_3DPipelinePractice/`에 03번과 동일한 3파일 구성을 만든다. 코드는 2D 것을 그대로 가져오고 파일명·함수명·표시 문자열(03→04, 2D→3D)만 일괄 교체한다. 로직은 사용자가 직접 수정 예정.
- 링크 충돌 방지를 위해 3D용 이름에 `3D`를 붙인다. 2D 기존 파일은 손대지 않는다.
- 신규: `04_3DPipelinePractice_Main.cpp`(서브메뉴, 기존 데모 코드 대체), `CPUTransformedVertex3D.cpp`(`CPUTransformedVertex3D_Main`), `GPUTransformedVertex3D.cpp`(`GPUTransformedVertex3D_Main`).
- `04_3DPipelinePractice_Main.h`(`Practice_3DPipelinePractice_Main` 선언), `PracticeRegistry.cpp` 수정 없음.
- `sgfr.vcxproj`, `sgfr.vcxproj.filters`에 3D용 `ClCompile` 2줄 추가. 기존 04 필터로 지정한다.
