# Practice 01~04 / 05~08 순서 교체 계획

## 1. 목표
- `02. Practice` 하위의 `01~04(씬 템플릿·연습)`와 `05~08(렌더링 파이프라인 템플릿·연습)` 순서를 맞바꾼다.
- `sgfr.vcxproj.filters` 필터명과 파일·폴더의 접두 숫자를 함께 교체한다.
- 함수명(`Practice_*_Main`)은 숫자를 포함하지 않으므로 유지한다.

## 2. 사전 분석 결과
- 현재 구성: 01 2D 씬 템플릿, 02 3D 씬 템플릿, 03 2D 씬 연습, 04 3D 씬 연습 / 05 2D 파이프라인 템플릿, 06 3D 파이프라인 템플릿, 07 2D 파이프라인 연습, 08 3D 파이프라인 연습.
- 각 폴더는 `_Main.h/_Main.cpp` 2개로 구성. 총 폴더 8개, 파일 16개.
- 번호 참조 위치: 폴더명, 파일명 접두(`01_`, `05_` 등), `#include` 경로, 파일 상단 주석(`01. 2D 씬 템플릿`), 본문 주석(`01번`, `이후 03번`), 콘솔(`[Practice 01]`), 윈도우 타이틀(`Practice 01. ...`), `PracticeRegistry.cpp`(include 8줄 + 배열 8줄), `sgfr.vcxproj`(16줄), `sgfr.vcxproj.filters`(Filter 정의 8개 + ClCompile 9줄 + ClInclude 9줄).
- 상호 참조: 01 템플릿 주석 `이후 03번` ↔ 03 주석 `01번`, 02 주석 `이후 04번` ↔ 04 주석 `02번`. 파이프라인군(05~08)은 상호 번호 참조 없음.

## 3. 설계 (맞바꿈 매핑)
-旧 05_2DPipelineTemplate → 新 01_2DPipelineTemplate (파일 `05_` → `01_`)
-旧 06_3DPipelineTemplate → 新 02_3DPipelineTemplate (파일 `06_` → `02_`)
-旧 07_2DPipelinePractice → 新 03_2DPipelinePractice (파일 `07_` → `03_`)
-旧 08_3DPipelinePractice → 新 04_3DPipelinePractice (파일 `08_` → `04_`)
-旧 01_2DSceneTemplate → 新 05_2DSceneTemplate (파일 `01_` → `05_`)
-旧 02_3DSceneTemplate → 新 06_3DSceneTemplate (파일 `02_` → `06_`)
-旧 03_2DScenePractice → 新 07_2DScenePractice (파일 `03_` → `07_`)
-旧 04_3DScenePractice → 新 08_3DScenePractice (파일 `04_` → `08_`)
- 필터 표시명: `01. 2D 렌더링 파이프라인 템플릿`, `02. 3D 렌더링 파이프라인 템플릿`, `03. 2D 렌더링 파이프라인 연습`, `04. 3D 렌더링 파이프라인 연습`, `05. 2D 씬 템플릿`, `06. 3D 씬 템플릿`, `07. 2D 씬 연습`, `08. 3D 씬 연습`.
- 충돌 회피를 위해 `git mv`로 임시명(`_tmp_*`)을 거쳐 최종명으로 이동한다.
- 내용 숫자 교체: `[Practice NN]`, `Practice NN.`, 상단 주석 `NN. ...`, `NN번` 참조(01→05, 02→06, 03→07, 04→08, 05→01, 06→02, 07→03, 08→04 쌍으로 치환).
- `PracticeRegistry.cpp`는 파이프라인군 4줄을 앞으로, 씬군 4줄을 뒤로 재배치한다.
