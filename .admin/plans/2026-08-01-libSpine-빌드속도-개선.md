# 2026-08-01-libSpine-빌드속도-개선

## 배경
- `libSpine.vcxproj` (Spine 런타임)의 C++ 6개 파일이 오래 걸림
- 원인 1: libSpine에 PCH 없음 → cocos2d.h 전체를 TU마다 재파싱
- 원인 2: x64 설정에 `/MP` 없음 → 직렬 컴파일

## 수정
- `libSpine.vcxproj`
  1. PCH 추가: `precheader.cpp`(Create) + 4개 설정에 `PrecompiledHeader=Use` / `ForcedIncludeFiles=precheader.h`
  2. `.c` 파일들은 repo 기존 패턴대로 `CompileAsCpp` 적용 (libcocos2d.vcxproj의 md5.c/xxhash.c 등과 동일)
  3. `Debug|x64` / `Release|x64`에 `<MultiProcessorCompilation>true</MultiProcessorCompilation>` 추가

## 검증
- msbuild로 libSpine Debug|x64 / Release|x64 빌드 성공 확인
- (선택) Scripts\Build-Cocos.bat 전체 빌드
