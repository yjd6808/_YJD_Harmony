# 콘솔 출력 잘림 수정 (2026-09-13)

## 목표
`Console::Write` 인자 분기의 1024자 초과 무출력 유실을 잘라서라도 출력되도록 수정한다.

## 방침
- 1024자 이내: 기존 스택버퍼 경로 그대로 (핫패스 변화 없음)
- 초과 ~ 64KB: 필요 길이 계산(`_sctprintf`) 후 힙에 담아 전부 출력
- 64KB 이상: 자르고 `...[이하 생략]` 마커 출력 + Debug 어서트
- `tprintf` 경로 유지 (`WriteConsoleW` 개조 아님), `Unicode`/`MultiByte` 양쪽 통과

## 순서
1. `Projects/jc/Sources/jc/Utils/Console.h` `Write` 인자 분기 수정 (1곳)
2. `Scripts\BuildProject\jcr.bat -C Debug -P x64` 빌드
3. `echo 0 | jcr.exe` 파이프 실행으로 메뉴 출력 UTF-8 검증 (원복 수정 regressions 체크 겸용)
