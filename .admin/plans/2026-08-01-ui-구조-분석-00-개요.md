- **UIElement** = `cc::Node` 파생. `uiSize_`(화면 크기), `_position`(부모 기준 좌하단), `state_`, 마우스 이벤트 리스트(`pMouseEventMap_`)를 가진다.

## 4. UI 텍스처 모드 (SGA vs THEME)

각 컨트롤은 `Load()` 시 `LoadLegacy()`(SGA 스프라이트)를 먼저 시도하고,
실패하면 `textureMode_ = UITextureMode::THEME`로 폴백하여 `LoadTheme()` → `BuildThemeVisuals()`를 실행한다.

- SGA 모드: `pTextures_[state][eMax]` / `pSprites_[state][eMax]` 배열에 스프라이트 로드 (레거시)
- THEME 모드: `UIThemeManager`가 Bake한 `UITextureSet`에서 `UIAssetKey`로 텍스처를 찾아 `UIThemeTextureBinding`으로 Scale9/Fixed 스프라이트에 바인딩

```
UIButton::Load()  (UIButton.cpp:250-267)
 ├─ LoadLegacy() 성공 → SGA 모드 (UIButton.cpp:269-299)
 └─ 실패 → THEME 모드
      └─ LoadTheme() → BuildThemeVisuals()  (UIButton.cpp:306-342)
           ├─ Resolve(Button, Normal) → styleHash
           ├─ UIAssetKey::For(Button, hash)
           ├─ themeBinding_.BindScale9(Scale9Sprite, key, Background)
           └─ themeBinding_.Refresh(*activeTextureSet)
```

## 5. 주요 용어

| 용어 | 의미 |
|---|---|
| `uiSize_` | 화면에 보이는 실제 UI 크기 (런타임 변경 가능) |
| `_contentSize` | 초기화 시 결정된 크기 (설정파일/기본값) |
| `UIAssetSemantic` | 시맨틱별 Bake 텍스처 종류 (Button, ToggleTrack, ...) |
| `UIResolvedStyle` | 해석 완료된 스타일 (색/기하/글로스) → `ComputeHash()`로 `styleHash` |
| `UIAssetKey` | `semantic + styleHash + recipeHash` → TextureSet에서 엔트리 조회 |
| `UITextureCacheKey` | `styleHash + recipeHash + stateHash` → Cache에서 엔트리 조회 |
