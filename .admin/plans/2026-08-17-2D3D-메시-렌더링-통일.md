# 2D/3D 메시 렌더링 통일 — GPU 변환 (최종 확정)

- 작성일: 2026-08-17
- 수정일: 2026-08-17 (사용자 확정: 템플릿 분리 취소 / StaticLevel = 월드 행렬 고정 / Bake 계열 전부 제거)
- 관련 문서: `.admin/plans/2026-08-17-엔진-코드리뷰-잔여.md` (A-1 / B-4 / C-2 / C-3)
- 전신: `.admin/plans/2026-08-17-Mesh-StaticLevel-도입.md` (StaticLevel 1차 구현 — 이 문서의 방향으로 재정의)
- 목적: 2D/3D 메시를 **동일한 파이프라인(GPU 변환)**으로 통일하고, 유니티/언리얼과 같은
  아키텍처로 전환한다. 정점은 로컬 공간에서 영원히 불변, 월드 정보는 상수버퍼(b1)로 전달.

---

## 1. 확정된 설계 결정

| 결정 사항 | 내용 |
|---|---|
| **Mesh 템플릿 분리** | **취소** — 단일 `Mesh` 클래스 유지 + `Is2D()` 런타임 체크. 유니티/언리얼과 동일. |
| **StaticLevel** | **GameObject 전담** — Mesh에서 완전히 제거. `slStatic` = 현재 월드 행렬 고정 보관 |
| **Bake/Unbake/IsBaked** | **전부 제거** — 정점 bake 개념 폐기. 검사는 `GetMeshStaticLevel()` 하나로 |
| **2D 메시 그리기** | CPU 변환+배칭 → **즉시 드로우** (Mesh::Bind → b1 갱신 → DrawIndexed) |
| **2D 셰이더** | Renderer2D 내장 스프라이트 셰이더에 **b1(world) + b2(baseColor) 추가** |
| **배치 경로** | 비메시 2D(사각형/원/스프라이트/DeclareStatic/UI)는 CPU 배칭 유지 — b1=단위행렬, b2=흰색 |
| **Phase 3(인스턴싱)** | 추후 콘텐츠 확장 시점 (이번 범위 아님) |

### 상세 근거

1. **Mesh = 순수 지오메트리**: 로컬 정점 + GPU VB/IB/InputLayout만 보유.
   CPU 미러(`cpuVertices_/cpuIndices_`), bake 캐시(`bakedVertices_/bakedIndices_`) 제거 → **A-1 완전 해소**.
2. **GPU 변환 통일**: 2D도 Renderer3D::Draw와 동일한 4단계
   (셰이더/상태 → `Mesh::Bind` → b1 갱신 → `DrawIndexed`). CPU 정점 변환 0회.
3. **StaticLevel은 GameObject 전담**:
   - `slStatic` 전환 시점의 월드 행렬을 GameObject가 보관 → `RenderSelf`가 현재 행렬 대신 고정 행렬 전달
   - `SetMeshStaticLevel(slStatic)` 재호출 = 새 위치로 재고정 (1차 구현의 "재구움"과 동일한 UX)
   - 검사는 `GetMeshStaticLevel()` 반환값 비교 하나로 충분 (IsBaked/Unbake 불필요)
4. **왜 Renderer2D 내장 셰이더인가**: GameObject 기본 머티리얼은 셰이더 키가 없다
   (`Material::Bind`는 키 필수 — Shape3D만 명시 지정). 내장 셰이더를 쓰면 재질 키 의존이 없고,
   배치 경로와 같은 b0(뷰프로젝션)를 그대로 재사용한다.
5. **틴트(재질 기본색)는 b2로**: 배치 경로는 b2=흰색 고정, 메시 경로는 재질 기본색 업로드.

### 드로우 순서 변화 (인지 필요)

메시는 트래버설 중 즉시 드로우되고, 배치(FlushStatic/FlushDynamic)는 씬 끝에 그려진다.
→ 메시는 배치된 콘텐츠보다 **항상 아래**에 그려진다. Renderer3D와 동일한 동작이며,
레이어(버킷) 개념은 비메시 배치 전용으로 남는다. (Phase 3 인스턴싱 시 순서 제어 재검토)

### 2-2. Mesh.cpp — Build2DPrimitive에서 CPU 미러 제거

**변경 전 (제거 대상):**

```cpp
bool Mesh::Build2DPrimitive(GraphicDevice* _pDevice, VertexShader* _pVs,
	const FillResult& _result, const char* _pName)
{
	if (_result.vertices_.Size() == 0 || _result.indices_.Size() == 0)
	{
		return false;
	}

	// CPU 미러 저장 (배칭/월드 변환용 — GPU 버퍼와 분리 보관. _u16은 PushTriangles 호환)
	cpuVertices_.Clear();
	cpuIndices_.Clear();
	for (const VertexPTC& vertex : _result.vertices_)
	{
		cpuVertices_.PushBack(vertex);
	}
	for (_u16 index : _result.indices_)
	{
		cpuIndices_.PushBack(index);
	}

	// GPU 초기화용 _u32 인덱스 배열 (Mesh::Initialize 입력 형식)
	jc::Vector<_u32> indices32;
	indices32.Reserve((_s32)cpuIndices_.Size());
	for (_u16 index : cpuIndices_)
	{
		indices32.PushBack((_u32)index);
	}

	UINT layoutCount = 0;
	const D3D11_INPUT_ELEMENT_DESC* pDescs = VertexPTC::LayoutDescs(&layoutCount);

	if (!Initialize(_pDevice, cpuVertices_.Source(), sizeof(VertexPTC), cpuVertices_.Size(),
		pDescs, layoutCount, _pVs, indices32.Source(), indices32.Size()))
	{
		return false;
	}

	format_ = VertexFormat::vfPTC2D;
	SetDebugName(_pName);
	return true;
}
```

### 2-5. Renderer2D.cpp — DrawMesh GPU 변환 전환 (핵심)

**변경 전 (현재 — CPU 변환 + 배칭):**

```cpp
void Renderer2D::DrawMesh(Mesh* _pMesh, Material* _pMaterial, const mat4& _world)
{
	if (_pMesh == nullptr || !_pMesh->Is2D())
	{
		return;
	}

	const _u32 vertexCount = _pMesh->GetVertexCount2D();
	const _u32 indexCount = _pMesh->GetIndexCount2D();
	if (vertexCount == 0 || indexCount == 0)
	{
		return;
	}

	// 텍스처 해석: 재질 0번 슬롯의 텍스처 → 없으면 기본 흰색 텍스처 (단색 도형)
	Texture* pTexture = g_cResourceMgr.GetDefaultTexture();
	if (_pMaterial != nullptr)
	{
		const _u64 textureKey = _pMaterial->GetTextureKey(0);
		if (textureKey != INVALID_RESOURCE_KEY)
		{
			Texture* pFound = g_cResourceMgr.Find<Texture>(textureKey);
			if (pFound != nullptr)
			{
				pTexture = pFound;
			}
		}
	}

	// 재질 기본색 = 틴트 (단색 도형의 채움색. 텍스처 스프라이트는 기본 흰색)
	const color tint = (_pMaterial != nullptr) ? _pMaterial->GetBaseColor() : color::WHITE;

	// StaticLevel::slStatic(A) — bake 캐시(이미 월드좌표)를 그대로 배칭. 월드 변환 계산 0회.
	// 트랜스폼 변경은 bake 시점에 고정됐으므로 _world 인자는 무시된다. (틴트만 매 프레임 적용)
	if (_pMesh->IsBaked())
	{
		meshScratch_.Clear();
		meshScratch_.Reserve((_s32)vertexCount);
		const VertexPTC* pBaked = _pMesh->GetBakedVertices();
		for (_u32 i = 0; i < vertexCount; ++i)
		{
			VertexPTC out;
			out.position_ = pBaked[i].position_;
			out.uv_ = pBaked[i].uv_;
			out.color_ = pBaked[i].color_ * tint;
			meshScratch_.PushBack(out);
		}
		PushTriangles(pTexture, meshScratch_.Source(), vertexCount, _pMesh->GetBakedIndices(), indexCount);
		return;
	}

	// CPU 미러 정점을 월드 변환 + 틴트 적용 (스크래치 재사용 — 매 호출 할당 없음)
	meshScratch_.Clear();
	meshScratch_.Reserve((_s32)vertexCount);
	const VertexPTC* pVertices = _pMesh->GetVertices2D();
	for (_u32 i = 0; i < vertexCount; ++i)
	{
		VertexPTC out;
		out.position_ = _world.TransformPoint(pVertices[i].position_);
		out.uv_ = pVertices[i].uv_;
		out.color_ = pVertices[i].color_ * tint;
		meshScratch_.PushBack(out);
	}

	PushTriangles(pTexture, meshScratch_.Source(), vertexCount, _pMesh->GetIndices2D(), indexCount);
}
```

**변경 후 (GPU 변환 즉시 드로우 — Renderer3D::Draw와 동일 구조):**

```cpp
void Renderer2D::DrawMesh(Mesh* _pMesh, Material* _pMaterial, const mat4& _world)
{
	if (_pMesh == nullptr || !_pMesh->Is2D())
	{
		return;
	}
	if (_pMesh->VertexCount() == 0)
	{
		return;
	}

	GraphicContext& context = pDevice_->GetContext();

	// 깊이/블렌드 상태 재확정 — Flush와 같은 이유. 3D와 섞여도 2D는 깊이 끄고 반투명.
	pDevice_->SetDepthTest(false);
	pDevice_->SetAlphaBlending(true);

	// 1. 어떻게 그릴지 — 셰이더 + b0(뷰프로젝션) 장착 (배치 공용 파이프라인)
	ApplyFrameStates();

	// 2. 무엇을 그릴지 — VB/IB/레이아웃/토폴로지 (로컬 정점 그대로 — 불변)
	_pMesh->Bind(context);

	// 3. 텍스처 해석: 재질 0번 슬롯 → 없으면 기본 흰색 텍스처 (단색 도형)
	Texture* pTexture = g_cResourceMgr.GetDefaultTexture();
	if (_pMaterial != nullptr)
	{
		const _u64 textureKey = _pMaterial->GetTextureKey(0);
		if (textureKey != INVALID_RESOURCE_KEY)
		{
			Texture* pFound = g_cResourceMgr.Find<Texture>(textureKey);
			if (pFound != nullptr)
			{
				pTexture = pFound;
			}
		}
	}
	if (pTexture != nullptr)
	{
		pTexture->Bind(pDevice_, 0);
	}

	// 4. b2 머티리얼 상수 = 재질 기본색 (틴트. 배치 경로는 흰색 고정 — 여기서만 갱신)
	MaterialConstants material;
	const color tint = (_pMaterial != nullptr) ? _pMaterial->GetBaseColor() : color::WHITE;
	tint.ToFloat4(material.baseColor_);
	materialCb_.Update(pDevice_, material);
	context.SetConstantBuffer(ShaderStage::ssPixel, 2, materialCb_.Raw());

	// 5. b1 오브젝트 상수 = 월드 행렬 (GPU 변환 — 정점은 로컬 공간 불변)
	ObjectConstants object;
	object.world_ = _world;
	objectCb_.Update(pDevice_, object);
	context.SetConstantBuffer(ShaderStage::ssVertex, 1, objectCb_.Raw());

	// 6. 드로우 콜 (인덱스 유무에 따라 DrawIndexed/Draw)
	++drawCallCount_;
	_pMesh->Draw(context);
}
```

**변경 후:**

```cpp
void GameObject::SetMeshStaticLevel(StaticLevel _level)
{
	staticLevel_ = _level;
	if (_level == StaticLevel::slStatic)
	{
		staticWorld_ = pTransform_->GetWorldMatrix();	// 현재 위치로 고정 (재호출 = 새 위치로 재고정)
	}
}

StaticLevel GameObject::GetMeshStaticLevel() const
{
	return staticLevel_;
}

void GameObject::RenderSelf()
{
	if (pMesh_ == nullptr || pScene_ == nullptr)
	{
		return;
	}
	// slStatic: 고정 행렬 / 그 외: 현재 월드 행렬 (GPU 변환 — 정점은 불변)
	const mat4& world = (staticLevel_ == StaticLevel::slStatic)
		? staticWorld_
		: pTransform_->GetWorldMatrix();
	pScene_->DrawMesh(pMesh_, pMaterial_, world);
}
```
