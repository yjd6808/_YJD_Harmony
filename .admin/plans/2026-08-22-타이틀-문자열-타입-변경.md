### 1-3. jc::String 특성

- 경로: `jc/Primitives/String.h` — `char*` 기반 UTF-8 문자열 (Source() / Length()).
- `String(const char*)` non-explicit → `"abc"` 리터럴 암시적 변환 가능, `L"abc"`는 불가.
- 기존 `jc::StringUtil::ToUtf8(const wchar_t*, int)` 는 wide→UTF8 변환만 제공, 역방향(UTF8→wide) 유틸 **없음**.
- 프로젝트 빌드 플래그 `/utf-8` 적용 중 → 소스 파일 내 `"한글"` narrow 리터럴은 UTF-8로 인코딩됨.

### 1-4. Windows API 제약

- 최종 호출 `CreateWindowExW` / `SetWindowTextW`는 `LPCWSTR(wchar_t*)` 필요 → 엔진 내부에서 UTF-8→UTF-16 변환 필수 (`MultiByteToWideChar(CP_UTF8)`).

## 2. 설계

### 2-1. 목표 시그니처

```cpp
// Window.h
bool Create(const jc::String& _title, _s32 _width, _s32 _height);
void SetTitle(const jc::String& _title);

// Application.h
bool Initialize(const jc::String& _title, _s32 _width, _s32 _height);
Window* CreateSubWindow(const jc::String& _title, _s32 _width, _s32 _height);
```

- 헤더에 `#include "jc/Primitives/String.h"` 추가.
- 기존 주석 `@param _title: 창 제목...` 유지, 타입만 갱신.

### 2-2. UTF-8 → Wide 변환 헬퍼

Window.cpp (내부 익명 namespace) 또는 별도 유틸에 추가:

```cpp
// 내부 헬퍼 — jc::String(UTF-8) → wchar_t 버퍼
static std::wstring Utf8ToWide(const jc::String& _utf8) // 또는 Vector<wchar_t>
{
    if (_utf8.IsEmpty()) return L"";
    int wlen = ::MultiByteToWideChar(CP_UTF8, 0, _utf8.Source(), _utf8.Length(), nullptr, 0);
    std::wstring out(wlen, L'\0');
    ::MultiByteToWideChar(CP_UTF8, 0, _utf8.Source(), _utf8.Length(), out.data(), wlen);
    return out;
}
// 또는 스택 버퍼 최적화: 짧은 타이틀( <256 )은 wchar_t[512] 스택, 긴 경우 힙.
```

- 구현 선택: `std::wstring` 간단, 혹은 힙 할당 최소화 위해 `wchar_t szBuf[512]` + fallback `new wchar_t[wlen+1]`.
- 변환 실패 시 `jc_assert` + 빈 문자열.

### 2-3. 구현부 수정

- `Window::Create`: 변환 후 `CreateWindowExW(..., wide.c_str(),...)` / `wide.data()`
- `Window::SetTitle`: `SetWindowTextW(hWnd_, wide.c_str())`
- `Application::Initialize`:
  - 로그 라인 `_LogInfo_("[sgf] ... title=%s", StringUtil::ToUtf8(...))` → `_title.Source()` 로 직접 사용 (이미 UTF-8).
  - `window_.Create(_title, ...)` 전달.
- `Application::CreateSubWindow` : 동일.

### 2-4. 호출부 마이그레이션 (sgfr)

| 기존 | 변경 |
|---|---|
| `app.Initialize(L"33. 프리미티브 쉐이프...")` | `app.Initialize("33. 프리미티브 쉐이프...")` (L 제거) |
| `CreateSubWindow(L"서브 윈도우",...)` | `CreateSubWindow("서브 윈도우",...)` |
| `GetWindow()->SetTitle(L"32. ...")` | `GetWindow()->SetTitle("32. ...")` |
| `wchar_t szTitle[128]; swprintf(...) ; window.SetTitle(szTitle);` | `jc::String title = jc::StringUtil::Format(...); window.SetTitle(title);` 또는 `jc::String title; title.Format(...);` |
| `SetTitleDrawCall(Window*, const wchar_t*, _u32)` 헬퍼 | `SetTitleDrawCall(Window*, const char*, _u32)` 로 시그니처 변경, 내부에서 `Format` 후 `SetTitle` |

- narrow 리터럴 내 한글은 소스 파일이 UTF-8이므로 `jc::String`에 UTF-8로 저장 → `Utf8ToWide`로 정상 복원.
- 필요 시 `jc::String title = "...";` 임시 변수로 전달 (const ref 바인딩).

### 2-5. 제외 / 유지

- `Texture::LoadFromFile(const wchar_t*)` 유지 (파일 경로, 이번 작업 범위 아님).
- `Director.h` 주석 예시 `L"미니맵"` → `"미니맵"` 으로 수정.

### 2-6. 호환성

- `const wchar_t*` 오버로드는 제공하지 않음 (요청대로 완전 교체).
- 빌드 에러로 모든 누락 호출부 노출되므로 컴파일러가 가이드.
