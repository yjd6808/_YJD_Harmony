# 방향 상수 추가

## 목표
- vec2/vec3/vec4에 왼손 좌표계 기준 방향 상수를 추가한다.
- 기존 PascalCase 명명(Up/Right/Forward) 유지.

## 규약 (왼손, Y-up)
- Right=+X, Left=-X, Up=+Y, Down=-Y, Forward=+Z, Backward=-Z
- vec4 방향 상수는 w=0 (방향 벡터, 이동 무관)

## 변경 파일
- Projects/jc/Sources/jc/Math.h (1개)

## 순서
1. vec2: Left/Right/Up/Down 추가
2. vec3: Left/Down/Backward 추가 (Up/Right/Forward 존재)
3. vec4: Zero/One + Left/Right/Up/Down/Forward/Backward 추가
4. jc + sgfr 빌드 검증
