## 1. 분석 결과 (실측)

- `Console.h` narrow 잔재: `CSI`/`VT_*` 매크로 narrow, `VTForeColor` 등 4종 `const char*`,
  `Write`/`WriteLine` 8종 `const char*` 포맷 + `printf`/`printf_s`/`putchar`/`sprintf_s`,
  `ReadLine`/`ReadLineBuffered`/`ReadKey`/`ReadKeyWhile`의 `const char*` 프롬프트 + `char` 버퍼,
  `ConsoleKeyInfo::KeyChar` `char`, `ReadKey` 내부 `AsciiChar` 고정.
- `Console.cpp`는 `ConvertColorString`만 `_T()` 완료. VT 테이블 정의, `ReadLine`(`std::cin`+`char`),
  `ReadKey`(`AsciiChar`), `Clear`의 `System("cls")` narrow가 남았다.
- 함께 되돌릴 임시 래핑: `ConsoleMenuItem.cpp` 9곳 + `ThreadPool.cpp` 3곳의
  `StringConvert::ToUtf8(...).Source()` (Console이 narrow라 넣었던 우회).
- 호출부 영향 (jc + jc_gtest): `Coroutine.cpp` DumpStack narrow, `MemoryPoolAbstract.h` 박스 리터럴,
  `WinApi.cpp` `"%s"` 1건, `_Extern/Extern_Console.cpp` narrow C-ABI 경계,
  `jc_gtest` `ThreadPoolTest.cpp`/`SchedulerTest.cpp` narrow 리터럴.

## 2. 설계 (제1규칙 5항 준수 — 새 `const char*` 금지, narrow 경계만 예외)

1. `Console.h`
   - `CSI`/`VT_*` 매크로 전부 `_T()`화. `CSI_GRAPHIC_RENDITION(x)`는
     `_T("\x1b[") _T(#x) _T("m")` 형태로 wide/narrow 모두 연결되게 한다.
   - `VTForeColor`/`VTBackColor`/`VTForeToken`/`VTBackToken` → `static const _char*`.
   - `Write`/`WriteLine` 8종 포맷 → `const _char*`, 배열 오버로드 → `_char(&)[N]`.
   - 출력은 제네릭 CRT로 교체: `printf`→`_tprintf`, `printf_s`→`_tprintf_s`... 계열,
     `putchar`→`_puttchar`, `sprintf_s`→`_stprintf_s`. (`A/W` 접미 직접 호출 금지 준수)
   - `ReadLine`/`ReadLineBuffered`/`ReadKey`/`ReadKeyWhile` 프롬프트 → `const _char*`,
     버퍼 → `_char*`, `ReadLine` 내부는 `_tcin` + `_char`, 개행 비교 `_T('\n')`.
   - `ConsoleKeyInfo` 생성자/`KeyChar` → `_char`. `ReadKey` 내부는 `_UNICODE` 인라인 분기로
     `UnicodeChar`/`AsciiChar` 선택 (제1규칙 3항, 헬퍼 신설 금지).
2. `Console.cpp`: VT 테이블 정의 `const _char*` + `_T()` 유지, `ReadLine`/`ReadKey`/`Clear`(`_T("cls")`) 전환,
   프롬프트 출력 `Write(_T("%s"), _pMsg)`.
3. `ThreadPool.h/.cpp`: `ToStateString` → `const _char*` + `_T()` 리터럴,
   `TASKPOOL_LOG` 포맷 `_T()`, `ToUtf8(m_DebugName)` 래핑 제거 후 `.Source()` 직접 전달.
   (`TASKPOOL_LOG` 현재 disable이지만 enable 대비 선행 정리)
4. `ConsoleMenuItem.cpp`: `ToUtf8(...)` 9곳 제거 후 `.Source()` 직접 + 포맷 `_T("%s")`,
   `displayText`는 `AString`→`String`으로 되돌림.
5. `Coroutine.h/.cpp` DumpStack: `_pTitle` → `const _char*`, tier 이름·포맷 `_T()`.
   (호출부 없음 실측, 선언·정의 2곳만)
6. `MemoryPoolAbstract.h`, `WinApi.cpp`: 포맷 리터럴만 `_T()` (인자 타입 불변).
7. `_Extern/Extern_Console.cpp`: C-ABI narrow 유지 (제1규칙 2항). 내부는 경계 변환만 수행:
   `Write/WriteLine`은 `FromAnsi(_pFmt)`→`String`→`Write(_T("%s"), ...)`,
   `WriteFmt` 계열은 narrow로 `vsprintf_s` 후 `FromAnsi`→`Write`,
   `ReadLineBuffered`는 `_pMsg`만 `FromAnsi`, 결과는 `ToAnsi`로 되돌림.
8. `jc_gtest` 2 파일: 리터럴만 `_T()` (한글 포함, UTF-8 저장 유지).
