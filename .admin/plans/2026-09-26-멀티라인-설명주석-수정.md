# 멀티라인 설명주석 수정 (후속)

## 배경

전수 변환에서 멀티라인 설명의 모든 줄에 `// : `를 붙였으나,
올바른 스타일은 첫 줄만 `// : `, 이후 줄은 `// `이다.

## 확정 규칙

```cpp
//////////////////////////////////////////////////////////////////////////////////////////
// : [씬 1] Shape2D — A(스태틱) 방식 편의 노드. 정적 2D 셰이프 4종을 절대좌표로 bake해 배치한다.
// (움직이는 2D 오브젝트가 필요하면 Mesh+GameObject — B 기본, 튜토리얼 32 씬 1 참고)
// 4개가 모두 같은 흰색 텍스처로 배칭되어 실제 GPU 드로우콜이 1번만 발생한다.
//////////////////////////////////////////////////////////////////////////////////////////
```

- 설명 블록의 첫 번째 비어 있지 않은 줄만 `// : ` 리터럴.
- 두 번째 줄부터는 `// ` (콜론 제거).
- `///`/`//!` (doxygen), 빈 `//` 줄은 손대지 않는다.
- 단일 줄 설명은 기존대로 `// : 설명`.
- 적용 범위: `.cpp`만. 인코딩/개행 보존.

## 절차

1. 컨벤션 문서에 멀티라인 예시 추가.
2. 후속 스크립트 dry-run → 적용 → 재실행 0건 확인.
3. 샘플 diff 육안 확인.
4. `jc`/`sgf`/`sgfr` (`-C Debug -P x64`) 빌드.

## 검증

- 스크립트 재실행 시 변경 0건.
- 3개 프로젝트 빌드 통과.
