# THEME 미적용 컨트롤 적용 (UIScrollBar / UIStatic / UIEditBox) - 작업 완료

**날짜**: 2026-08-01
**목적**: 아직 THEME이 적용되지 않은 UIScrollBar / UIStatic / UIEditBox 3종에 기존 UIButton/UIProgressBar와 동일한 THEME(Bake) 폴백을 적용하고, 기존 스프라이트 배열·히트테스트·드래그·위치 계산 구조는 유지한 채 디버그 로그로 배치/위치를 검증

## 변경 파일

### Bake 인프라 확장
- `Theme/Baker/UIControlBakeRecipes.h/.cpp`: `ScrollBarThumbRecipe(int)`(slice 8,8,8,8, min 16×16), `EditBoxRecipe(int,int)`(slice 10,10,10,10, min 20×20) 추가
- `Theme/UITextureBakeService.cpp` `SelectRecipe()`: `ScrollBarThumb → ScrollBarThumbRecipe(24)`, `EditBox → EditBoxRecipe(160,44)` 추가
- `Theme/UIThemeManager.cpp` `BakeDefaultTextureSet()`: 기본 시맨틱 16종 → 18종 (ScrollBarThumb, EditBox 추가), semantic→UIElementType 매핑에 `ScrollBarThumb→ScrollBar`, `EditBox→EditBox` 추가

### UIScrollBar (`UI/UIScrollBar.h/.cpp`)
- `init()`: pPack null이어도 `isInitialized_=true` (THEME 폴백 허용, false→true 변경)
- `Load()`: `LoadLegacy()` 성공 시 SGA / 실패 시 `textureMode_=THEME; LoadTheme()` 폴백
  - `LoadLegacy()`: 기존 `CreateSprites()` 로직 이관, **7개 스프라이트 전부 로드 성공 시에만 SGA 판정** (부분 로드 시 크래시 방지, 텍스처 링크/실패 시 릴리스 처리)
- `LoadTheme()/BuildThemeVisuals()/RefreshThemeVisuals()`: track(`ScrollBarTrack` Scale9), thumb normal/pressed(`ScrollBarThumb` Scale9, pressed 색 180,180,200), up/down(`Button` 시맨틱 Scale9, pressed 색) 생성, `themeBinding_` 바인딩
- `Unload()`: `themeBinding_.Clear()` 추가
- `SetUISize()`: THEME 분기 (비-thumb 스프라이트 contentSize + `UpdateTrackAndButtonPosition/UpdateThumbSize/UpdateThumbPosition` 재호출)
- `UpdateThumbSize()/UpdateThumbPosition()`: 디버그 로그 추가
- `CreateSprites()` 잔여 선언 제거

### UIStatic (`UI/UIStatic.h/.cpp`)
- 기존 디버그 스프라이트(`pDebugTexture_`)를 **THEME Frame Scale9**로 교체 (`themeRoot_`, opacity 125, Africanviolet)
- `Load()`: THEME 고정 → `BuildThemeVisuals()`, `Unload()`에 `themeBinding_.Clear()`
- `SetUISize()`, `SetDebugVisible()` THEME 분기, 디버그 로그 추가

### UIEditBox (`UI/UIEditBox.h/.cpp`)
- `Load()/Unload()/BuildThemeVisuals()/RefreshThemeVisuals()` 추가
- `EditBox` 시맨틱 Scale9 배경을 `localZOrder=-1`로 pEditBox_ 뒤에 배치, `SetUISize()` 시 themeRoot 동기화, 디버그 로그 추가

## 확인된 기존 문제 (이번 작업과 무관, 별도 조사 예정)
1. **Release 실행 크래시**: `CharInfoLoader::Load → 의존성(Item) 로드`에서 0xC0000005. 변경을 `git stash`로 제거한 원본 소스 빌드로도 재현됨 → 기존 소스/환경 이슈. Debug 빌드는 정상 실행
2. **배포 assets XML 구형 형식**: `ui_inventory.xml` 등이 `track_size="11 98"`인데 현재 `UIXmlLoader::ParseScrollBar`는 `track_width`/`track_height` 속성만 파싱 (assets 업데이트 필요)
3. **BuildProject/*.bat 경로 버그**: `BUILD_PS1=%~dp0..\..\Scripts\Build.ps1`이 실제로 `Scripts\Scripts\Build.ps1`을 가리킴 (sgcl.bat/sgcc.bat 공통)
4. **Build-Cocos 선행 조건**: libcocos2d 링크에 sgcc.lib 필요 → `sgcc.bat`(또는 전체 sgcl 체인) 선행 빌드 필수 (AGENTS.md에 미기재)
