# 2026-08-01 THEME 미적용 컨트롤 적용 (UIScrollBar / UIStatic / UIEditBox)

> 위치: `Projects/sgcl/Classes/sgcl/Game/UI/`

## 목표

SGA(레거시) 이미지가 없는 환경에서도 모든 UI 컨트롤이 THEME(Bake) 텍스처로 그려지도록,
아직 THEME이 적용되지 않은 컨트롤 3종에 기존 UIButton/UIProgressBar 패턴을 동일하게 적용한다.

- **UIScrollBar**: track→`ScrollBarTrack`, thumb→`ScrollBarThumb`(신규 bake), up/down 버튼→`Button` 시맨틱 재사용
- **UIStatic**: `Frame` 시맨틱 (Scale9)
- **UIEditBox**: `EditBox` 시맨틱 배경 (Scale9, pEditBox_ 뒤에 삽입)

## 핵심 원칙

1. **기존 구조 유지** — 스프라이트 배열/히트테스트/드래그/위치 계산 로직은 그대로 두고, 텍스처 출처만 SGA→THEME 폴백
2. **기존 THEME 패턴 재사용** — UIButton 패턴: `Load()` → `LoadLegacy()` 성공 시 SGA / 실패 시 `textureMode_=THEME; LoadTheme() → BuildThemeVisuals() → themeBinding_ → Refresh(*pSet) → setContentSize(uiSize_) 복구`
3. **디버그 로그 심기** — Load/BuildThemeVisuals/SetUISize/UpdateThumbPosition 단계에서 모드·위치·크기·텍스처셋 상태를 `_LogDebug_`로 출력하여 배치 검증
