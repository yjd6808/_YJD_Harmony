# Practice 05~08 렌더링 파이프라인 추가 계획

## 1. 목표
- `Tutorial/05_RenderingPipeline`을 참고해 Practice 05~08을 신설한다.
- 01~04 폴더 패턴을 따른다. 템플릿은 독립 기반 코드, 연습은 템플릿 복사본이다.
- `vcxproj`, `vcxproj.filters` 등록을 포함한다.
- 주석은 작성자명/생성일만 남기고 추가 작성하지 않는다.

## 2. 사전 분석 결과
- 01/02는 Scene 기반 템플릿, 03/04는 각 템플릿 복사본이다. 각 폴더는 `_Main.h/_Main.cpp` 2개로 구성된다.
- 기존 `Practice/05_RenderingPipeline`은 준비 중 placeholder이며 삭제 후 교체한다.
- Tutorial 05는 Simple 경로(`gd.Create/gc.Set/DrawIndexed`)로 NDC 삼각형을 그린다. 2D 템플릿은 이 경로만 사용한다.
- Tutorial 13은 상수버퍼(`CbTransform`)와 `LookAtLH/PerspectiveFovLH`, 깊이 버퍼로 큐브를 그린다. 3D 템플릿은 이 구조를 사용한다.
- Practice 참조는 `PracticeRegistry.cpp`, `sgfr.vcxproj`, `sgfr.vcxproj.filters` 3곳에만 존재한다.

## 3. 설계
- 신규 폴더 4개, 파일 8개. 함수명은 `Practice_2DPipelineTemplate_Main` 형식이다.
- 05 2D 템플릿: NDC 삼각형, Simple 경로, ESC 종료. 셰이더 문자열 자체 포함이다.
- 06 3D 템플릿: 정점 8개/인덱스 36개 큐브, `CbTransform` 회전, 깊이 읽기/쓰기 고정. SPACE 토글은 제외한다.
- 07/08: 05/06 복사본. 함수명과 타이틀만 07/08로 변경한다.
- 삭제 2개: 기존 `05_RenderingPipeline` `_Main.h/_Main.cpp`와 빈 폴더.
- 수정 3개: `PracticeRegistry.cpp`, `sgfr.vcxproj`, `sgfr.vcxproj.filters`.
- 새 파일명은 Tutorial과 충돌하지 않으므로 `ObjectFileName` 분리가 필요 없다.

## 4. 파일 목록
