## 5. UIXmlLoader (UIXmlLoader.cpp) — 레이아웃 XML 파싱

`UIManager::Show(name)` (UIManager.cpp:46-110) 내부에서 호출되는 XML 로더.

### 5-1. 파싱 흐름
```
UIXmlLoader::Load(xmlPath, rootGroup)  // UIXmlLoader.cpp:25-...
 ├─ tinyxml2 로 XML 문서 로드
 ├─ <UI> 루트 → <Elements> → 각 요소 순회
 │    foreach element tag (Button/CheckBox/ToggleButton/ProgressBar/Label/Static/Sprite/EditBox/Group...)
 │      factory = UI_FACTORY에서 타입명 매핑 (UIRegister.h:5-16 REGISTER_UI)
 │      instance = factory->Create() → pRootGroup_->AddElement()
 │      ApplyElementAttributes(instance, xmlNode)   // 공통 속성
 │      instance->InitFromXml(...)                  // 타입별 속성
 │      instance->Load()                            // 텍스처 로드(SGA/THEME)
 ├─ 자식 그룹 재귀 (Group 요소 안의 Group)
 └─ rootGroup->Load()  → OnLoaded()  → OnAdded()
```

### 5-2. 공통 속성 (ApplyElementAttributes)
| 속성 | 설명 | 기본값 |
|---|---|---|
| `id`/`name` | 요소 이름 (FindElementByName 키) | - |
| `type` | 컨트롤 타입 (Button 등) | - |
| `pos_x`/`pos_y` | 위치 (상대) | 0,0 |
| `size` | `width,height` | 0,0 |
| `anchor_x`/`anchor_y` | 앵커 | 0.5 |
| `halign`/`valign` | 정렬 (0=Left/Top, 1=Center, 2=Right/Bottom) | 0 |
| `zorder` | Z 순서 | 0 |
| `visible` | 표시 여부 | true |
| `disabled` | 비활성 | false |
| `state` | 초기 상태 (ToggleButton 등) | - |
| `draggable` | 드래그 가능 | false |
| `onclick` | 클릭 이벤트 id | - |
| `bg_color` | 배경색 | - |
| `texture` | SGA 이미지 경로 (레거시) | - |
| `font_size`/`font_name` | Label용 | - |
| `clip` | 클리핑 여부 (UIScrollView) | false |
| `percent` | ProgressBar 초기값 | 0 |
| `is_check` | CheckBox 초기 체크 | false |
| `gap` | Group 자식 간격 | 0 |
| `padding` | Group 패딩 | 0 |
| `position_type` | Group 자식 배치 (Layout) | Absolute |
| `on_toggle_changed` | 토글 콜백 id | - |
| `on_check_changed` | 체크 콜백 id | - |

## 6. InitFromXml → Load → OnLoaded 흐름 (화면 구현체 예: UI_Generic)

```
UIManager::Show("ui_generic")                          (UIManager.cpp:46-110)
 └─ UIXmlLoader::Load("layout/ui_generic.xml", root)
     └─ 각 요소 create + InitFromXml + Load (SGA/THEME 자동)
 └─ root->Load()        → 파생 구현 (UI_Generic::Load)
 └─ root->OnLoaded()    → UI_Generic::OnLoaded() (UI_Generic.cpp:53-99)
     └─ FindElementByName("...") → SetUISize/SetPercent/SetCheckState 등 초기화
 └─ root->OnAdded()     → UILayer에 추가, 표시
```

`REGISTER_UI(ui_generic, UI_Generic)` (UI_Generic.cpp:10) — UIManager::Show가 팩토리에서 `UI_Generic` 생성 가능.
`UIManager::Show`는 `{resDataPath_}/layout/{이름}.xml` 경로를 읽는다. (UIManager.cpp:52-55)

## 7. 예외: UI_Popup 은 팩토리 미사용

```
PopupManager::CreatePopup(...)  (PopupManager.cpp:46-56)
 └─ UI_Popup 을 직접 new → Init → Load → (XML 로더 없이 코드로 구성)
```
- UI_Popup 은 `UIXmlLoader` 를 거치지 않고 코드에서 자식 노드/컨트롤을 직접 구성한다. (UI_Popup.cpp:35 부근)
- 생성 후 `SetTitle`/`SetContent`/`AddButton`/`ShowPopup` 등 API 사용.
