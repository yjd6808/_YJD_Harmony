# 2026-08-01 테마/스키마 실시간 전환 지원

## 목표
Aurum UI Theme Studio v1.7 스타일의 **JSON 테마 파일을 런타임에 로드/전환**하고,
**스키마(Dark/Light)** 를 실시간으로 바꿔 모든 열린 UI에 즉시 반영되도록 한다.

- 트리거: `ui_generic.xml`에 테마/스키마 전환 버튼 추가 (클릭 처리)
- 테마 소스: Aurum 형식 JSON (`meta/surface/gold/gloss/semantic/geometry/state`)
- 스키마: 같은 JSON에서 Mapper가 Dark/Light 팔레트 생성 (System→Dark 유지)

## 현재 상태 (분석 결과)
- `UIThemeMapper::Map()`이 JSON `_source`를 **무시**하고 procedural 팔레트만 생성 (ReadColor 미구현)
- `UIThemeManager::Update()`가 게임 루프에서 **호출되지 않음** → 비동기 베이크/전환 불가
- 컨트롤 `RefreshThemeVisuals()`는 **재해석 없이** 기존 키로만 재바인딩 → 테마 교체 시 키 불일치
- 테마 교체 후 열린 화면 전체에 리프레시 통지 경로 없음
- `UIColorScheme {Light, Dark, System}` 열거는 존재, 활성 스킴 관리 없음

## 작업 계획

### 1. UIThemeMapper — Aurum JSON 파싱 구현
- `ReadColor`: JSON `"#RRGGBB"` → UIColorF
- `Map(source, scheme)`: JSON 토큰 → UIRuntimeTheme 전체 매핑
  - `surface` → surface (10색), `gold` → metal (6색), `gloss` → gloss, `semantic` → semantic, `geometry` → geometry, `state` → state, `meta` → meta
  - JSON에 없는 필드는 EngineDefaults 유지
- 스킴 처리: Dark=JSON 그대로 / Light=표면·금속 반전 팔레트 (surface 밝게, text 반전 등)
- 기존 `Mix/ResolveScheme` 유지

### 2. UIThemeManager — 전환 API + Update 연결
- `ApplyTheme(themeJsonPath, scheme)`:
  1. JSON 로드 → `mapper_.Map` → UIRuntimeTheme
  2. `activeTheme_` 교체, `revision_.mappedRevision++`
  3. 베이크 요청(비동기, generation=sourceRevision+1)
  4. 완료 시 열린 모든 화면 재귀 리프레시
- `SetScheme(scheme)` / `GetScheme()`
- `Update(dt)` 연결: `Layer_UI::OnUpdate` (Layer_UI.cpp:197)에서 호출 추가

### 3. 컨트롤 RefreshThemeVisuals 재해석
- UIButton / UICheckBox / UIToggleButton / UIProgressBar:
  - `RefreshThemeVisuals()`가 `Resolve(현재 상태)` → 새 키 → `BindScale9/BindFixed` 재바인딩하도록 수정
  - 상태별(평소) 재해석은 Normal 기준 유지, `setContentSize(uiSize_)` 복구
- UIGroup에 `RefreshThemeVisualsRecursive()` 추가 (자식 재귀 호출)
- UIRootGroup에서 오버라이드로 루트부터 재귀

### 4. 테마 JSON 파일 추가 (Aurum 형식)
- `assets/res_data/theme/` 아래 2개:
  - `modern-dark-gold.json` (예시 modern-dark-gold.theme.json 기반, Dark)
  - `modern-light-silver.json` (Light용 — 표면 밝은 실버 골드)
- `ui_generic.xml`: 전환 버튼 2~3개 추가 (theme_next / scheme_toggle 등)

### 5. UI_Generic 버튼 처리
- `OnMouseUpTarget`에서 전환 버튼 클릭 처리 → `UIThemeManager::ApplyTheme` / `SetScheme`
- 클릭 시 로그 출력 (테마명, 스키마, revision)
