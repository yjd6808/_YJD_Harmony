# 계획: sgcl/sgfr 솔루션 빌드 오류 수정

- 날짜: 2026-08-09
- 대상: UltimateHarmony 메인 워크트리 (`sg-main`)
- 범위: `Projects\sgf`, `Projects\sgfr` 내 코드만 수정 (jc 등 타 프로젝트 무수정)

## 확인된 근본 원인

1. `Scene.h` 블록 주석 내부에 `/* 로직 */`, `/* 정리 */` 중첩 → 주석 조기 종료
   → Scene.h 하위 라인과 dependents(SgfMath/Camera/GraphicDevice/Renderer2D/3D/Application)에서 연쇄 파싱 오류
2. sgf PCH `Core.h`에 `jc/TypeCast.h` 미포함 → `jc::Memory.h:94 AddressOf` C3861/C2668
3. `Buffers.h`에서 `GraphicDevice`를 전방 선언만 사용 → C2027 (완전 정의 필요)
4. `SoundEngine.cpp:422`가 `TwoPi_v` 사용하나 `SgfMath.h` 미포함 → C2065

## 조치

1. `Scene.h` 주석 중첩 제거 (로직/정리 주석을 `{ ... }` 스타일로)
2. `PCH/Core.h`에 `#include "jc/TypeCast.h"` 추가
3. `Buffers.h`의 전방 선언 → `#include "sgf/Graphics/GraphicDevice.h"`
4. `SoundEngine.cpp`에 `#include "sgf/Math/SgfMath.h"` 추가
5. 재빌드 반복, 추가 오류 처리
6. sgfr 빌드까지 성공 확인
