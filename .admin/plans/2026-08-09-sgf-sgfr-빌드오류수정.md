# 완료: sgcl/sgfr 솔루션 빌드 오류 수정

- 날짜: 2026-08-09
- 대상: UltimateHarmony 메인 워크트리 (`sg-main`)
- 범위: `Projects\sgf`, `Projects\sgfr` 내 코드만 수정 (jc 등 타 프로젝트 무수정)
- 플랜: `.admin/plans/2026-08-09-sgf-sgfr-빌드오류수정.md`
- 결과: **전체 솔루션(`Harmony_Full-NoEngine.sln`) 빌드 성공 (exit 0)**, sgfr.exe 실행 정상 확인

## 근본 원인

1. `Scene.h` 블록 주석 내부에 `/* 로직 */`, `/* 정리 */` 중첩 → 주석 조기 종료
   → Scene.h 하위 라인과 dependents(SgfMath/Camera/GraphicDevice/Renderer2D/3D/Application)에서 연쇄 파싱 오류 (C2059/C2447 등 수백 개)
2. sgf PCH `Core.h`에 `jc/TypeCast.h` 미포함 → `jc::Memory.h:94 AddressOf` C3861/C2668
3. `Buffers.h`에서 `GraphicDevice` 전방 선언만 사용 → C2027 (완전 정의 필요)
4. `SoundEngine.cpp:422`가 `TwoPi_v` 사용하나 `SgfMath.h` 미포함 → C2065
5. (sgfr) PCH `Core.h`가 존재하지 않는 `jc/Core.h`를 include → 파일 없음 오류
6. (sgfr) `TutorialRegistry.h/.cpp`에 `sgfr` 네임스페이스 누락 → Main.cpp의 `sgfr::` 참조 C2039
7. (sgfr) `Props/sgf.props` 누락 — sgfr.vcxproj가 Import하던 파일
