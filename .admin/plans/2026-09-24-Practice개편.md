# Practice 구조 개편 (2D/3D 씬 템플릿 도입)

## 목표
- `Practice/01_RenderingPipeline`을 `05_RenderingPipeline`으로 이동한다. (번호 체계 정리)
- Practice 하위에 2D/3D 씬 기반 연습 체계를 만든다.
- 2D 씬 기반 코드를 간단하게 작성한다.

## 최종 구조
- `Practice/01_2DSceneTemplate/01_2DSceneTemplate_Main.h/.cpp` — 함수 `Practice_2DSceneTemplate_Main()`
- `Practice/02_3DSceneTemplate/02_3DSceneTemplate_Main.h/.cpp` — 함수 `Practice_3DSceneTemplate_Main()`
- `Practice/03_2DScenePractice/03_2DScenePractice_Main.h/.cpp` — 함수 `Practice_2DScenePractice_Main()`
- `Practice/04_3DScenePractice/04_3DScenePractice_Main.h/.cpp` — 함수 `Practice_3DScenePractice_Main()`
- `Practice/05_RenderingPipeline/05_RenderingPipeline_Main.h/.cpp` — 기존 01 이동, 함수명 유지

## 필터 구성
- `02. Practice\01. 2D 씬 템플릿`
- `02. Practice\02. 3D 씬 템플릿`
- `02. Practice\03. 2D 씬 연습`
- `02. Practice\04. 3D 씬 연습`
- `02. Practice\05. 렌더링 파이프라인`

## 등록 순서 (PracticeRegistry.cpp)
1. 2D 씬 템플릿
2. 3D 씬 템플릿
3. 2D 씬 연습
4. 3D 씬 연습
5. 렌더링 파이프라인

## 기반 코드 방침
- 01 2D 템플릿: `Application` 파생 + `Scene2D` 파생 최소 구성. 직교 카메라 800x600, `DriveDefault2D` 이동/줌, `g_cRenderer2D.DrawRect` 1개 + 안내 콘솔 출력. ESC 종료.
- 02 3D 템플릿: `Application` 파생 + `Scene3D` 파생 최소 구성. `DrawGrid + DrawAxis + DrawCube` 1개. ESC 종료.
- 03 2D 연습: 01 템플릿을 복사한 독립 코드. 클래스명 `Practice2DScene`/`Practice2DApp`, 이후 연습 내용은 씬에 직접 채운다.
- 04 3D 연습: 02 템플릿을 복사한 독립 코드. 클래스명 `Practice3DScene`/`Practice3DApp`, 이후 연습 내용은 씬에 직접 채운다.
- 05 렌더링 파이프라인: 기존 placeholder 내용 유지, 파일 경로와 include만 변경한다.
