# SGCL UI 전체 구조 분석 - 03. 이벤트 호출 구조 (트리: 파일명:함수:라인)

> 작성일: 2026-08-01
> 이 문서는 마우스/키보드/상태 변경 이벤트가 Cocos → UI 시스템 → 컨트롤 → 화면 구현체로 전달되는 전체 호출 트리를 정리한다.
> 좌표는 `파일명:함수:라인` 형식. 경로는 `Projects/sgcl/Classes/sgcl/Game/` 기준.

## 9. 마우스 이벤트 리스트 등록 API (UIElement)

```cpp
AddMouseEvent(MouseEventType, int id, jc::Action<EventMouse*>)   // UIElement.h:129-131
RemoveMouseEvent(MouseEventType, int id)                          // UIElement.h:132
InvokeMouseEvent(MouseEventType, EventMouse*)                     // UIElement.cpp:636-644
```
- `MouseEventType` (UIElement.h:16-26): Down/Move/Up/UpContained/Scroll/Leave/Enter/Max
- `pMouseEventMap_[eMouseEventMax]` (UIElement.h:175) — 이벤트 타입별 `SGMouseEventList`(=jc::Event) 맵
- **현재 대부분의 화면 로직은 이 리스트 대신 `OnMouse*Target` + `OnMouse*InternalDetail` override를 사용한다** (레거시 지원용 API)

## 11. 좌표계 규칙 (디버깅 시 유의)

- **bottom-left 원점**: `_position`은 부모 노드 기준 좌하단. `GetPositionCenter()` = `_position + uiSize/2` (UIElement.cpp:405-410)
- `GetAbsolutePosition()` = 부모 체인을 따라 `_position` 누적 (UIElement.cpp:386-396)
- `IsContainPoint()` = `{_position, uiSize_}` 사각형에 커서 포함 여부 (UIElement.cpp:143-155)
- UIGroup은 자식으로 이벤트 전달 시 `mousePos - _position`으로 로컬 좌표 변환 후 `CursorPositionGuard`(RAII)로 원복 (UIGroup.cpp:20, 242-247)
- `SetRelativePosition(x,y)` = 정렬 기준 위치 + 오프셋 (UIElement.cpp:599-604)
- VAlignment 기본값(0)=Top, HAlignment 기본값(0)=Left (SteinsGate_UI.h:22-25 참고, XML `valign="2"` = Bottom)
