## 1. 배경

`sgf/Scene`에 `Shape2D.h/cpp`(2D 프리미티브 자동 드로우 편의 노드)만 존재한다.
3D에도 동일한 편의 노드 `Shape3D`가 필요하다.

- Shape2D: OnEnter에서 `Scene2D::DeclareStaticXX`로 절대좌표 1회 bake (정적)
- Shape3D: 3D에는 "스태틱 bake" 개념이 없으므로, `SetMesh + 머티리얼 구성`을 OnEnter에서 1회 수행하고
  OnRender에서 `RenderSelf()`로 메시 자동 드로우 (Transform 이동/회전/스케일 — 움직이는 3D 도형)

## 3. Shape3D API 설계

```cpp
class Shape3D : public GameObject
{
public:
    explicit Shape3D(const char* _pName = "Shape3D");

    // AddChild 전에 설정 (OnEnter에서 1회 구성)
    void SetShape(PrimitiveMesh3DType _type, const color& _color);

    // Transform 편의 래퍼 (한 줄 배치)
    void SetPosition(const vec3& _position);
    void SetScale(const vec3& _scale);            // 오버로드: uniform
    void SetRotationEuler(_f32 _xDeg, _f32 _yDeg, _f32 _zDeg);

protected:
    virtual void OnEnter() override;   // 메시 조회 + 셰이더 키 + baseColor + Material::Initialize
    virtual void OnRender() override;  // RenderSelf() — 메시 자동 드로우

private:
    PrimitiveMesh3DType type_ = PrimitiveMesh3DType::Cube;
    color color_ = color::WHITE;
};
```
