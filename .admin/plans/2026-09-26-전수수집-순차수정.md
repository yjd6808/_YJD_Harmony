# 전수수집 + 순차수정 (jc/jnet/sgf/sgfr)

## 방식

1. 수집만 병렬 에이전트 (수정 금지). 스크립트 금지, Read 직접 열람.
2. 수집 항목을 섹션으로 묶고 1~N 번호를 매긴다.
3. 수정은 직접 하나씩 순서대로 수행한다.
4. 동일 수정이 섹션 단위면: 소규모는 파일:줄:내용 명시 후 수정,
   대규모는 섹션마다 빌드 후 오류 수정.

## 수집 기준 (컨벤션 + 주석 품질)

- coding-conventions_cpp.md 전체 (구분자/설명 옵션 포함).
- 주석 품질: 과한 설명, 버그 수정 이력, 버전 이력,
  주석처리된 죽은 코드, 기능 파악을 방해하는 장황한 주석.
- 보고는 2단계: 확정 위반 / 판단 필요(의도적 패턴 의심).

## 영역 (21개)

- jc 10개 (기존 분할 유지), jnet 3개, sgf 4개, sgfr 4개.
