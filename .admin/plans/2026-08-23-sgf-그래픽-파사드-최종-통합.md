## 2. RenderingPipeline 수도 코드 → 파사드 결정

- **초안**: `RenderingPipeline pipe; pipe.CreateSwapChain(옵션); pipe.CreateVertexBuffer<T>(); pipe.Draw(); pipe.Present();`
- **최종 결정**: 별도 `RenderingPipeline` 클래스 폐기. D3D11의 `Device(Create/소유)` / `Context(Set/Draw)` 경계를 따라 `GraphicDevice`(수명·생성·표면·프레임) / `GraphicContext`(바인딩·상태·드로우)로 직접 흡수. `Window`는 OS 창만, `SwapChain/Depth` 소유는 `GraphicDevice`(추후 `RenderingPipeline`이 Window 핸들로 생성)로 역전

## 3. 소유권 분리 (v3)

- **GraphicContext**가 `SgfComPtr<ID3D11DeviceContext> pContext_` + `pDevice_/deferred_` 소유. `InitializeImmediate/Deferred` 신설, 복사 금지·소멸자 추가, `SetRenderTargets`에 `cachedRtvCount_` 추가
- **GraphicDevice**는 `pDevice_`만 소유. `CreateDeviceOnly/AndSwapChain`에서 `SgfComPtr pImmediate`로 생성 후 `context_.InitializeImmediate`로 이관, `Finalize`는 `context_.Finalize() → states → surface → pDevice_` 역순
- `SwapChain::ApplyFullViewport`/`DepthStencilSurface::Clear` 시그니처를 `GraphicContext&`로 변경, `GraphicDevice`의 `pContext_->` 직접 호출 11곳을 `context_.Set*`로 치환

## 4. 블로커 0-1~0-5 + B-1/D-2/A-1 (즉시 수정)

- **0-1~0-3**: `InitializeImmediate/Deferred` 정의 누락·`Finalize` `ClearState` 누락·`Initialize` 위임 미흡 수정
- **0-4**: `SetRenderTargets` 캐시에 `cachedRtvCount_` 추가
- **0-5**: `SwapChain.h`/`DepthStencilSurface.h` 전방선언 중복 병합
- **B-1**: 양쪽 생성 경로에 `MakeWindowAssociation(DXGI_MWA_NO_ALT_ENTER)` 추가
- **D-2**: `Width()/Height()/width_/height_` 미사용 확인 후 삭제, `CreateDeviceAndSwapChain(HWND,w,h)` 시그니처 변경
- **A-1~A-4**: 실패 시 `Reset()` 후 재시도, `DXGI_ERROR_SDK_COMPONENT_MISSING`일 때만 디버그 플래그 제거 재시도(`_LogWarn_`), `HARDWARE` 실패 시 `WARP` 폴백, 피처 레벨 `{11_1,11_0,10_1,10_0}` 확장 및 선택 레벨 로그, `RefreshRate 0/0`

## 5. 상태 API 세대교체

- `RenderStates`에서 `GetDepthState(bool)`/`GetRasterizerState(bool,..)`/`GetSamplerState(2인자)` 3종 삭제, `Initialize`의 `GetSamplerState` 호출을 3인자로 교체
- `GraphicDevice`의 `SetDepthTest`/`SetSampler` 내부를 `DepthMode`/`3인자` enum 경로로 교체, `ApplyRasterizerState`는 `GetRasterizerState(Cull,Fill,Front)`로 교체

## 6. 표면·프레임·바인딩 단일화

- `SwapChain::ApplyFullViewport`/`DepthStencilSurface::Clear`를 `GraphicContext&` 경유로 변경, `GraphicDevice`의 `BindWindowSurface` 등 4곳을 `context_.SetRenderTargets/SetViewport/Clear*`로 치환
- `Vertex/Index/ConstantBuffer::Bind/Update`를 `GraphicContext&`로 변경, `Shader::Bind`도 `GraphicContext&`로 변경, `GraphicContext::UpdateBuffer` 신설, `Renderer2D/3D/Material` 호출부를 `GetContext()` 경로로 이관
- `GraphicContext`에 `SetRasterizer(Cull,Fill,Front)/SetBlend(BlendMode)/SetDepth(DepthMode)/SetSampler(Filter,Address,slot)` enum 설탕 추가, `Context()`를 `GetContext()`에서 개명(`GraphicContext&` 반환) 및 `Raw()` 경유로 이관

## 7. 싱글턴·레지스트리·설탕 (최종 설계서 4-5단계)

- **싱글턴**: `GraphicDevice::Get()` Meyers static 추가, 복사 금지 유지, `IsValid()` 추가, 소멸자 `Finalize()` 백스톱
- **레지스트리**: `INVALID_HANDLE`, `ShaderSlot/VertexBufferSlot/LayoutSlot` 3종, `CreateShader/CreateVertexBuffer<T>/CreateIndexBuffer/CreateTexture` 4종(생성=즉시 current), `Resolve*/EnsureInputLayout`, `CreateSwapChain(HWND,w,h,PixelFormat)`, 코어 `BeginFrame(SwapChain&,Depth*,color)` 선언 추가 (cpp 본문은 다음 커밋에서 채움)
- **헤더 정리**: `jc/Container/Vector.h` 포함, `스왕체인→스왑체인` 등 오타 일괄 수정, `SetDebugName` 추가
