### 기존 인프라
- `FrameTimer::Fps()` 존재 (1초마다 갱신). `dt`는 `timer_.Delta()` (TimeSpan).
- `Renderer2D::GetDrawCallCount()` 존재 — `OnBegin`(렌더러 배치 시작)에서 0으로 리셋, `Flush()`의 DrawIndexed마다 증가.
  ⚠️ **주의**: 오버레이도 Renderer2D 배치를 열면(OnBegin) 카운터가 리셋되므로, **카운터 읽기(Collect)는 오버레이 배치 시작 전에 해야 한다.**
- `Renderer3D`는 드로우콜 카운터 **없음** → 신규 추가 필요.
- `Renderer2D` 즉시 모드(`Begin(행렬)`→`DrawRect`...→`End()`) 존재 — "씬 밖/디버그 용도"로 유지된 경로. 오버레이 렌더에 사용.
- `Application::Run` 프레임 흐름: `BeginFrame → g_cDirector.Render(씬) → OnRender() → EndFrame`. 오버레이는 `OnRender()` 뒤, `EndFrame` 앞에 삽입.
- `g_cInput.IsKeyPressed(VK_F12)` — 프레스 엣지 판정 (토글에 적합).
- 텍스트 렌더링 시스템 없음 → TextRenderer 신규.
- vcpkg 통합 사용 중 (`D:\_Dev\vcpkg\installed\x64-windows` — VcpkgTripletSelection 로그 확인). freetype 설치/링크 가능.

## 2. 라이브러리 결정: FreeType

| 항목 | FreeType (선정) | stb_truetype (대안) |
|---|---|---|
| 글리프 지원 | TTF/OTF(glyf/CFF), WOFF, Type1, 비트맵(BDF/PCF), 컬러 이모지(CBDT/COLR), SVG | TTF/OTF(glyf)만 — CFF·이모지 불가 |

- **선정: FreeType** (vcpkg 설치). 한글(맑은 고딕 등 시스템 폰트 로드)과 향후 확장(이모지) 모두 커버.
- 1차 범위: **단색 글리프(알파 아틀라스) + UTF-8 텍스트**. 컬러 이모지(CBDT/COLR)는 후속 단계로 유보.
- 폰트 소스: 시스템 폰트 로드 `C:\Windows\Fonts\malgun.ttf`(맑은 고딕 — 한글) → 실패 시 `arial.ttf` 폴백. 별도 에셋 파일 불필요.
- 쉐이핑: 한글은 성형음절(완성형) 폰트라 HarfBuzz 불필요 (1차 범위에서 제외).

## 2-1. SDF(서명 거리 필드) 검토 — 후속 확장으로 유보

사용자 질의: FreeType과 SDF 적용 방법, 성능 충분 여부.

**결론: 1차는 FreeType 스캔라인(단색 알파 아틀라스). SDF는 후속 단계로 유보.**

- 프레임당 비용은 둘 다 동일 (아틀라스 캐시 → 텍스처 쿼드 드로우 1회). 래스터라이즈는 1회성이므로
  "성능"이 아니라 "품질/기능" 선택이다.
- 고정 크기(오버레이 16px) 텍스트는 스캔라인+힌팅이 최고 품질. SDF는 큰 크기에서 아틀라스
  해상도 한계(테셀 밀도)로 품질 저하, 뾰족한 획은 MSDF(3채널) 필요.
- SDF가 필요한 시점: 월드 공간 텍스트(3D), 줌/스케일 UI, 아웃라인·글로우 이펙트.
- **후속 적용 경로 (설계 여지 확보)**:
  1. TextRenderer를 "글리프 생성 → 아틀라스 → 드로우" 3단계로 분리 설계 → 생성 단계만 교체.
  2. SDF 생성: FreeType 2.11+ 내장 `FT_RENDER_MODE_SDF` (단일 채널, 라이브러리 추가 없음)
     또는 msdfgen (MSDF — 품질 최고, 소스 빌드 필요).
  3. 아틀라스 포맷에 SDF 플래그 + 전용 픽셀 셰이더(smoothstep + fwidth) 추가.
  4. DrawText에 크기 파라미터 자유화 (스캔라인: 크기별 아틀라스 / SDF: 1개로 전 크기).

## 3. 설계

### 3-1. `sgf/Graphics/TextRenderer.h/.cpp` (신규) — FreeType 래퍼
- `Initialize(GraphicDevice*)` — FT_Init_FreeType + 폰트 face 로드 + 아틀라스 텍스처 생성 (예: 512x512, 알파 8비트 → DX11 R8 텍스처).
- **동적 글리프 아틀라스**: 첫 사용 시점에 해당 유니코드 글리프만 FT_Render_Glyph로 래스터라이즈 → 아틀라스 여유 영역에 복사 (캐시 맵: 코드포인트 → UV). 사용된 글리프만 메모리 차지 → 한글/기호 어떤 폰트든 자동 지원.
- `DrawText(const char* _utf8, const vec2& _pos, const color& _color, _f32 _pixelHeight)` — 글자별 아틀라스 UV로 쿼드 생성, `Renderer2D::DrawSprite(아틀라스 텍스처, ..., _uvMin, _uvMax)`로 배칭 (같은 텍스처 연속 → 드로우콜 1회).
- 색상은 DrawSprite 틴트로 처리. 크기 조절은 폰트 픽셀 높이 기준.
- 줄바꿈(`\n`) 지원. 정렬은 좌상단 기준.

### 3-2. `sgf/Core/DebugOverlay.h/.cpp` (신규) — 스탯 수집 + 화면 표시 + 토글
- 멤버: `bool enabled_`(기본 true), `bool prevToggle_`(F12 엣지 판정), 캐시 문자열.
- `Collect()` — **오버레이 배치를 열기 전에 호출**:
  - FPS: `g_cTimer.Fps()`
  - 프레임 시간: `g_cTimer.Delta()` → ms (소수 1자리)
  - 2D 드로우콜: `g_cRenderer2D.GetDrawCallCount()`
  - 3D 드로우콜: `g_cRenderer3D.GetDrawCallCount()` (신규)
  - 2D 스태틱 캐시 수: `g_cRenderer2D.GetStaticCacheCount()` (신규 게터)
  - 창 크기: `g_cWindow.Width()/Height()`
- `Draw(Renderer2D& _renderer, const mat4& _ortho)` — 배치 시작 상태에서 문자열들을 좌상단(8,8)부터 렌더. 반투명 배경 사각형(DrawRect, 검정 a=160) + 흰색/연노랑 텍스트.
- 표시 형식 (1줄 예):
  `FPS: 60.0  |  dt: 16.7ms  |  DrawCall 2D: 1  |  DrawCall 3D: 6  |  Static2D: 5  |  800x600`
- 토글: `Application::Run`에서 `g_cInput.IsKeyPressed(VK_F12)` 엣지 → `enabled_` 반전.
- 카운터 리셋 문제 해결: Collect(읽기) → 오버레이 배치 Begin(리셋됨, 무시) → Draw 순서로 보장.

### 3-3. `Renderer3D` 드로우콜 카운터 추가
- `Renderer3D.h`: `_u32 drawCallCount_` + `GetDrawCallCount()`. `OnBegin`에서 리셋(현재 OnBegin은 Clear만 함).
- 증가 지점: `Draw(Mesh*, Material*, mat4)` 1회당 +1 (메시 파이프라인), `FlushBatch` 1회당 +1 (배치 파이프라인).

### 3-4. Application 통합
- `Application.h/.cpp`:
  - 멤버: `TextRenderer textRenderer_; DebugOverlay overlay_;`
  - `Initialize()`: 리소스매니저 뒤, Renderer2D/3D 뒤에 `textRenderer_.Initialize(&device_)` 추가 (실패 시 경고 로그 후 계속 — 오버레이만 꺼짐).
  - `Run()` 메인 윈도우 그리기: `OnRender()` 뒤에
    `overlay_.Collect(); if (overlay_.IsEnabled()) { renderer_.Begin(직교행렬); overlay_.Draw(renderer_, ...); renderer_.End(); }`
  - 직교행렬: `Camera2D::SetOrthographic2D`와 동일 구성 (0,0 = 좌상단, y 아래로 증가 — DirectXMath OrthographicOffCenterLH). SubWindow는 그리지 않음 (1차).
  - F12 토글 처리: `overlay_.Update(g_cInput.IsKeyPressed(VK_F12))` — 씬 갱신 단계.
  - `Finalize()`: `textRenderer_.Finalize()` 추가.
- `SgfHeader.h`: TextRenderer.h, DebugOverlay.h include 추가.

### 3-5. sLogFrame 제거 (4개 파일, 위 표의 위치)
- 전부 삭제. 해당 정보는 오버레이가 대체 (배칭 검증용 DrawCall 수가 화면에 상시 표시되므로 로그 불필요).
