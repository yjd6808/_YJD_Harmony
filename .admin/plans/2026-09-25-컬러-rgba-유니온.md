# 컬러 rgba 유니온 확장

- 날짜: 2026-09-25
- 대상: `Projects/jc/Sources/jc/Math.h`의 `struct color` (1개 파일)

## 목표

- `color`의 `r, g, b, a`를 `_u32 value`로도 다룰 수 있게 union으로 묶는다.
- 기존 코드(`r/g/b/a` 접근, `color(r,g,b[,a])` 생성, `FromFloat`, `Rf()/ToVec4()/ToFloat4()`,
  `operator*`, 정적 상수 344종, 정점 버퍼 `R8G8B8A8_UNORM` 4B stride)는 그대로 동작한다.

## 성공 기준

1. `color c(0xFF, 0, 0); c.value == 0xFF0000FF` (리틀엔디안, 하위 바이트부터 r,g,b,a).
2. `color::FromRgba(0xFF0000FF)`가 빨강을 만든다.
3. `sizeof(color) == 4` 유지 (static_assert로 고정).
4. `Scripts\BuildProject\jc.bat -C Debug -P x64` 통과.

## 순서

1. `Math.h`의 `r, g, b, a` 선언을 익명 union으로 감싸고 `_u32 rgba`를 겹친다.
2. packed 생성자(`explicit constexpr color(_u32)`)와 `FromRgba`를 `FromFloat` 옆에 둔다.
3. struct 종료 지점에 `static_assert(sizeof(color) == 4)`를 둔다.
4. jc Debug/x64 빌드로 검증한다.

## 검증

- 빌드 스크립트: `Scripts\BuildProject\jc.bat -C Debug -P x64`
- C++ 변경이므로 빌드 생략 불가. 테스트 추가는 범위 밖(jc_gtest에 color 테스트 없음).
