# Fill.cpp 구분자 추가

## 대상

`Projects/sgf/Sources/sgf/Graphics/Fill.cpp` 1개 파일.
구분자가 전혀 없는 함수 11개에 구분자+설명을 추가한다.

## 내역

| 함수 | 설명 출처 |
|---|---|
| `ResolveTexture` (익명) | 기존 `//` 1줄 → `// :` 승격 + 상하단 구분자 |
| `FillSolid` | 기존 1줄 → 승격 + 구분자 |
| `FillTexture` | 기존 1줄 → 승격 + 구분자 |
| `FillNinePatch` | 기존 2줄 → 첫 줄만 `// :`, 둘째 줄 `//` + 구분자 |
| `FillGauge` | 기존 1줄 → 승격 + 구분자 |
| `Fill::Solid/Texture/NinePatch/Gauge/Custom/CustomData` | `Fill.h` 팩토리 주석 기반 신규 1줄 설명 + 구분자 |

- 구분자 길이 90 (들여쓰기 레벨 0). 하단 구분자와 함수 사이 빈 줄 없음.
- 143행 Custom 안내 주석은 `Solid()` 설명이 아니므로 일반 주석으로 유지.
- 주석은 동작/의도만 기술 (아키텍처 결정 내용 금지).

## 검증

- `sgf.bat -C Debug -P x64` 빌드 통과.
