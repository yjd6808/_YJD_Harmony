# mat4 union 접근 도입

## 목표
- mat4에 union으로 _11~_44 명명 접근을 추가한다. (D3DXMATRIX 호환 명명)
- m[4][4]와 동일 메모리 공유, row-major 유지 (_11=m[0][0]).
- 명시적 원소 지정 코드는 _11 표기로 통일, 루프 코드는 m 유지.

## 변경 파일
- Projects/jc/Sources/jc/Math.h (1개)

## 순서
1. mat4 멤버를 union { struct { _11.._44 }; _f32 m[4][4]; } 로 교체
2. Translation/Scale/Rotation/LookAt/Perspective/Ortho를 _11 표기로 교체
3. vec2/vec3/vec4::Mul 정의부를 _11 표기로 교체
4. SetIdentity/operator*/Transposed 루프는 m 유지
5. jc + sgfr 빌드 검증
