### GPU 경계 (color가 float로 직접 읽히는 곳)
1. **정점**: `VertexPC`/`VertexPTC.color_` (COLOR R32G32B32A32_FLOAT, Vertex.h:33/56)
   → `_u8`(4바이트)이 되면 `DXGI_FORMAT_R8G8B8A8_UNORM`으로 필수 변경. (HLSL float4 시그니처 그대로 — IA가 정규화)
   VertexPTC 36B→24B, VertexPC 16B→16B(유지).
2. **Material cbuffer b2**: `MaterialConstants.baseColor_`(Material.h:35, color float4 16B)
   → `_f32 baseColor_[4]`로 변경. `SetBaseColor`에서 `ToFloat4` 변환, `GetBaseColor`는 값 반환으로.
3. **Clear**: GraphicDevice.cpp:279/307, RenderTarget.cpp:186 — `_clearColor.r` → `_clearColor.Rf()`.
4. **튜토리얼 자체 cbuffer 구조체** (`ConstantBuffer<T>`는 sizeof 16배수 static_assert):
   - 12 `CbObject.tint_`, 14 `CbLight.baseColor_`, 24 `CbShading.baseColor_`, 27 `CbLight.baseColor_`
   - `color` 필드 → `vec4`로 변경, 대입은 `color::XXX.ToVec4()`.
   - 27 `CbLight` 레이아웃: {vec3+_f32} + vec4 + {_f32+padding[3]} = 64B 유지.

## 설계 (새 color)
```cpp
struct color
{
	_u8 r, g, b, a;
	constexpr color();                              // 불투명 흰색 (255,255,255,255)
	constexpr color(_u8 _r, _u8 _g, _u8 _b, _u8 _a = 255);
	constexpr color(int _r, int _g, int _b, int _a = 255);  // 헥스/정수 리터럴, 0~255 클램프
	static color FromFloat(_f32 _r, _f32 _g, _f32 _b, _f32 _a = 1.0f);  // 런타임 float→_u8 (라운드+클램프)
	_f32 Rf() const;  _f32 Gf() const;  _f32 Bf() const;  _f32 Af() const;  // GPU float
	vec4 ToVec4() const;                                  // cbuffer float4
	void ToFloat4(_f32 (&_out)[4]) const;                 // ClearRenderTargetView
	constexpr color operator*(const color&) const;        // 틴트: (r*o.r/255)
	color operator*(_f32 _s) const;                       // 밝기: FromFloat(rf*_s)
	static constexpr color WHITE; ...  // 9종 + 339색
};
```
- 상수명: ALL_CAPS snake (`CORNFLOWER_BLUE`). 339색은 원본 식별자에 대문자 경계마다 `_` 삽입 후 ALL_CAPS.
  (예: `AbsoluteZero`→`ABSOLUTE_ZERO`, `Acidgreen`→`ACIDGREEN`, `AmaranthMampP`→`AMARANTH_MAMP_P`)
- 프리셋 중복으로 목록에서 제외: `Black`(0x000000), `Blue`(0x0000FF), `Cyan`(0x00FFFF), `Cornflowerblue`(0x6495ED).
  → color.inl = **9 + 335 = 344개** 상수. 전부 불투명(a=255), 3바이트 값은 목록 그대로.
- 프리셋 값: WHITE FFFFFF / BLACK 000000 / RED FF0000 / GREEN 00FF00 / BLUE 0000FF /
  YELLOW FFFF00 / CYAN 00FFFF / MAGENTA FF00FF / CORNFLOWER_BLUE 6495ED(표준 웹 값).
