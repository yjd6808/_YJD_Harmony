## 2. 발견된 불일치 유형 (전 문서 공통)

| 유형 | 예시 | 대응 |
|---|---|---|
| 경로 `Tutorial/` 누락 | `sgfr/Sources/sgfr/01_LinearAlgebra/` | `Tutorial/` 삽입 |
| SceneRenderer → Renderer3D | v3 리팩터링으로 SceneRenderer 삭제, Renderer3D가 흡수 | 클래스명/파일 참조 교체 |
| color float 생성자 표기 | `color(0.5f, ...)` — jc::color는 정수 생성자만 존재 | 16진수 표기로 교체 |

| printf → jc::Console::Write | 문서 스니펫 | `jc::Console::Write`로 교체 |
| VertexPC/PTC 크기 | 28B/32B/36B → 실제 16B/24B | 바이트 계산 전면 재계산 |
| 백버퍼 2장 vs BufferCount=1 | 3.7MB 서술 | 1장 1.83MB로 수정 |
| 디폴트 리소스 7종 → 17종 | CreateDefaults가 프리미티브 메시 10종 추가 등록 | 17종 기준 재작성 |
