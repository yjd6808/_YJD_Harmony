# Assert 경로 TCHAR화 계획 (2026-09-12, 사용자 지정)

- `Path.h` narrow 오버로드는 유지 확정(호출 0건). 대신 assert가 넘기는 파일명/함수명을
  문자셋을 따라가게 한다: `_UNICODE`면 wide, 아니면 narrow.
- `_FILEW_`/`_WFUNCTION__` 매크로는 컴파일러에 없으므로 2단 `JC_WIDEN`으로 만든다.

## 1. 설계

1. `Assert.h`: `JC_WIDEN2`/`JC_WIDEN` + `JC_FILE`/`JC_FUNC` 선택 매크로 신설.
   `__DebugAssertMsgImpl`의 `_filePath`/`_functionName`만 `const _char*`로 변경
   (`_expectStr`는 `#` 결과가 narrow라 그대로 + `%hs`). 매크로는 `JC_FILE`, `JC_FUNC` 전달.
2. `Path.h/.cpp`: `FileNameLevel(_char*, int, const _char*, int, int)` buf판 신설
   (narrow판 미러, 힙 없음 유지). 나머지 narrow판은 MB 충돌(`_char`==`char` 중복 정의)로 유지.
3. `Assert.cpp`: 버퍼 `_char`, `StringUtilT::Length`, 파일명/함수명 `%s` 출력.
