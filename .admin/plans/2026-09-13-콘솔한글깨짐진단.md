# 콘솔 한글깨짐 진단 (2026-09-13)

## 목표
jcr 메뉴 한글이 `???`로 나오는 원인을 임시 진단 코드로 확정한다.

## 현황
- `Config.cpp`의 `SetOutputCodePage(UTF8)`는 `#ifdef _UNICODE` 가드로 제외됨
- 실행 시 `GetConsoleOutputCP() == 949` 확인됨 → CP 가설 탈락
- 남은 용의자: `printf(narrow)` vs `wprintf(wide)` 스트림 방향 선점, 리다이렉션/로케일 문제

## 순서
1. `jcr/Sources/jcr/main.cpp`에 임시 진단 블록 삽입 (콘솔 판별, WriteConsoleW, Console::Write, wprintf, narrow printf, 로거 순서대로 + 반환값 기록)
2. 진단 결과 파일로 기록 (`Temp/opencode/jcr_console_diag.txt`, UTF-8)
3. `Scripts\BuildProject\jcr.bat -C Debug -P x64` 빌드 (jc→jcr 순서로 빌드됨)
4. exe 실행 후 진단 파일 판독, 원인 확정
5. `main.cpp` 원복 + 재빌드로 정리

## 확정 (사용자 F5 결과)
- `isConsole=1, outCP=949` 실콘솔인데 `T1 WriteConsoleW`만 정상, `T2/T3(wprintf)`는 `??`/`-1`
- 즉 `wprintf`가 CRT 로케일(`C`) 변환을 타서 콘솔 도달 전에 이미 깨짐
- narrow UTF8 경로(`T4/T6`)는 CP949에서 깨져 보이는 게 정상 → CP는 65001이 맞아야 함

## 수정
1. `jc/Sources/jc/Config.cpp`: `setlocale(LC_ALL, ".UTF8")` 추가 + `SetOutputCodePage(UTF8)` 무조건 수행(가드 제거)
2. 진단 블록으로 파이프 바이트 검증 후 `main.cpp` 원복 + 재빌드
