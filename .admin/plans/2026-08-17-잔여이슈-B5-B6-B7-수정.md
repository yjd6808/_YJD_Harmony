## 설계

### B-5 — lazy dirty (노드별 stamp)

- 전역 시계 `g_transformStamp` (Transform.cpp 파일 정적). SetDirty/setParent 시 1 증가.
- 각 노드: `dirtyStamp_`(변경 시각) / `computedStamp_`(계산 시각).
- setter는 `dirtyStamp_ = ++g_transformStamp`만 — **자식 전파 없음** (O(1)).
- GetWorldMatrix 조회 시 부모 체인 최대 stamp > computedStamp_면 재계산 (O(깊이)).
- 부모가 먼저 재계산해도 dirtyStamp_는 유지되므로 자식이 나중에 조회해도 감지 가능 (정확성 보장).
- `GameObject::PropagateTransformDirty / PropagateTransformDirtyRecursive` 제거.
- 멤버 `worldDirty_` 제거.
- **부수 효과**: 전파 제거로 `pOwner_` 멤버가 미사용이 되어 함께 제거 (생성자 파라미터는 호출 규약 유지). 생성 시 stamp를 부여해 최초 조회에 반드시 계산되도록 보장.

### B-6 — ViewProjection 캐시

- `Camera.h`: `vp_`(mutable 캐시) + `vpDirty_`(mutable 플래그), `InvalidateViewProjection()`.
- Camera2D::Rebuild2D / Camera3D::Rebuild3D 끝에서 무효화 — 모든 파라미터 변경이 이 둘로 수렴.
  (Camera3D::SetPerspective는 projection_ 직접 설정 + Rebuild3D 호출 → 커버됨)

### B-7 — 경로 별칭 제거

- `ResourceBase`에 `path_` 멤버 + `GetPath()/SetPath()` 추가 (모든 리소스는 ResourceBase 파생 — 기존 static_cast 패턴과 일치).
- `Add(resource, path)`에서 SetPath.
- `RemovePathEntry`: 선형 탐색 제거 — `Find(_key)` → `GetPath()` → `pathIndex_.Remove(path)`.
  (Remove()가 리소스 삭제 **전**에 호출하므로 Find 가능 — ResourceMgr.cpp:197)

### B-1 — 상태 캐시 불일치 (P0): 우회 경로 제거

- **1단계 — GraphicContext에 Raw 오버로드 4종 추가** (기존 핸들 버전과 같은 캐시 필드 공유):
  - `SetBlendStateRaw(ID3D11BlendState*)`, `SetDepthStencilStateRaw(ID3D11DepthStencilState*)`,
    `SetRasterizerStateRaw(ID3D11RasterizerState*)`, `SetSamplerRaw(ShaderStage, slot, ID3D11SamplerState*)`
- **2단계 — GraphicDevice 직접 OMSet 4곳을 캐시 경유로 교체** (시그니처 유지 — 호출부 무변경):
  - `SetDepthTest` → `context_.SetDepthStencilStateRaw(states_.GetDepthState(...))`
  - `SetBlendMode` → `context_.SetBlendStateRaw(states_.GetBlendState(...))` (SetAlphaBlending은 SetBlendMode 경유 — 자동 커버)
  - `SetSampler` → `context_.SetSamplerRaw(ssPixel, slot, states_.GetSamplerState(...))`
  - `ApplyRasterizerState` → `context_.SetRasterizerStateRaw(states_.GetRasterizerState(...))`
- **3단계 — 프레임 경계 캐시 무효화**: `BeginFrame(Window*)`와 구버전 `BeginFrame(color)`에 `context_.InvalidateCache()` 1회.
- **부수 효과**: Renderer2D/3D의 상태 중복 설정(A-5/A-6)이 캐시 스킵으로 자동 해소.
- **위험 (수용)**: 튜토리얼 23의 `skippedCallCount_` 집계 변화 — 매 프레임 첫 바인딩이 실제 호출로 집계.

### B-3 — Material 상태 객체 비공유: RenderStates 풀 공유

- Material이 자체 PipelineState 핸들 4종(D3D 상태 객체)을 생성/보유하던 것을, **설정 키(enum) 8개만 보관**하도록 교체.
  Bind 시점에 `GraphicDevice::States()`(RenderStates 풀 — 지연 생성 캐시)에서 조회해 **B-1의 Raw 오버로드로 바인딩**.
- **Material.h**: 핸들 멤버 `rasterizer_/blend_/depth_/sampler_` 제거 → 키 멤버
  `blendMode_/depthMode_/cullMode_/fillMode_/frontFace_/filter_/addrU_/addrV_` 추가.
  Getter 4종(`GetRasterizer/GetBlend/GetDepth/GetSampler`) — 외부 사용처 없음 확인 → 제거.
  `PipelineState.h` include 제거 (GraphicContext.h 경유로 이미 포함됨).
- **Material.cpp**:
  - `Initialize`: 상태 객체 생성 4개 제거 — `pDevice_` 저장 + `constantBuffer_.Create`만.
  - setter 4종: 키만 갱신, `pDevice_` assert 유지(Initialize 필수 계약 유지), 반환 true.
  - `Bind`: `pDevice_->States()`에서 풀 조회 → `Set*StateRaw` 4종 바인딩.
- **효과**: 동일 설정 재질 N개가 풀의 객체 1개를 공유 → 포인터 비교 캐시 히트 → 재바인드 제거.
  C-5(재질 전환 상태 재바인드)도 자동 해소. 상태 객체 수명이 디바이스 수명으로 승격.
- **위험**: 없음 (시그니처 유지 — 튜토리얼 20 등 호출부 무변경). RenderStates 풀은 4x2x2 샘플러/블렌드/깊이/래스터 배열 전 조합을 지연 생성 지원.
