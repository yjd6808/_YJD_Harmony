## 1. 텍스처란?

지금까지는 정점 색을 보간해 칠했습니다. 하지만 캐릭터 얼굴을 정점 색으로 표현할 수는 없죠.
**텍스처 = 삼각형에 붙이는 이미지 스티커**입니다.

게임의 거의 모든 비주얼은 결국 "텍스처 붙은 사각형"입니다. Cocos2d-x의 Sprite도 정확히 이것입니다.

---

## 2. UV 좌표 — 이미지 위의 주소 체계

이미지의 어느 부분을 정점에 붙일지 지정하는 좌표가 UV입니다.

```
(0,0) ───── (1,0)
  │  이미지   │      u: 가로 (0 = 왼쪽 끝, 1 = 오른쪽 끝)
  │           │      v: 세로 (0 = 위 끝,   1 = 아래 끝)  ← DX는 v가 아래로 증가!
(0,1) ───── (1,1)
```

- 해상도와 무관하게 항상 0~1 (NDC와 같은 철학)
- 사각형 네 꼭짓점에 (0,0), (1,0), (0,1), (1,1)을 주면 이미지 전체가 붙음
- RS가 픽셀마다 UV를 보간(04번!)해주므로, PS는 그 UV로 이미지를 읽기만 하면 됨

그래서 정점 타입이 `VertexPTC`(Position + Texcoord + Color)가 됩니다.

## 3. PNG 파일이 화면에 나오기까지의 여정

### 3-1. 디코딩: PNG → 픽셀 배열 (WIC 사용)

PNG는 압축 포맷이라 GPU가 직접 못 읽습니다. 압축을 풀어 RGBA 바이트 배열로 바꿔야 합니다.
sgf는 Windows 내장 디코더인 **WIC**(Windows Imaging Component)를 씁니다. 외부 라이브러리 없이 PNG/JPG/BMP/GIF를 읽을 수 있습니다.

`Texture::LoadFromFile` 내부 흐름:

```
파일 → WIC 디코더 → 32비트 RGBA로 변환 → 픽셀 배열 → GPU 텍스처 생성 → SRV 생성
```

### 3-2. SRV (Shader Resource View)

03번에서 배운 "허가증" 개념의 세 번째 등장입니다. 텍스처를 **셰이더가 읽을 수 있도록** 허가하는 View입니다. `texture.Bind(&device, 0)`이 t0 슬롯에 SRV를 꾂아줍니다.

### 3-3. 샘플러 (Sampler) — 이미지를 "어떻게" 읽을지

UV가 픽셀과 픽셀 사이를 가리키면? 확대해서 그리면? 이런 규칙을 정하는 것이 샘플러입니다.

- **필터**: Point(계단현상, 도트게임 느낌) vs Linear(부드럽게 섮기) — sgf 기본은 Linear
- **주소 모드**: UV가 0~1을 벗어나면? Wrap(반복 타일) / Clamp(가장자리 색 유지)

sgf는 초기화 때 기본 샘플러를 s0 슬롯에 자동으로 바인딩해둡니다.

### 3-4. PS에서 샘플링

```hlsl
Texture2D    gTexture : register(t0);
SamplerState gSampler : register(s0);

float4 PSMain(VSOutput _input) : SV_TARGET
{
	float4 texColor = gTexture.Sample(gSampler, _input.uv); // UV 위치의 색 읽기
	return texColor * _input.color; // 정점 색과 곱해 틴트/페이드 효과 가능
}
```

## 4. 알파 블렌딩 — 투명한 부분 처리

PNG의 장점은 투명 배경(알파 채널)입니다. 하지만 GPU는 기본적으로 알파를 무시하고 덮어씁니다.
**블렌딩**을 켜야 OM 단계(04번!)에서 기존 색과 새 색을 알파 비율로 섮습니다.

```
최종색 = 새색 × 알파 + 기존색 × (1 - 알파)   ← lerp와 같은 공식! (05번)
```

```cpp
device.SetAlphaBlending(true); // 투명 PNG 그리기 전에 켜기
```

> 주의: 블렌딩은 "이미 그려진 색"과 섮으므로 **뒤에 있는 것을 먼저** 그려야 합니다. 2D 게임에서 깊이 테스트를 끄고 그리는 순서로 앞뒤를 정하는 이유입니다(09번 참조).

1. 프로그램이 직접 생성한 체커보드 PNG가 사각형에 붙어 표시됩니다. (외부 이미지 파일 없이도 동작하도록 메모리에서 생성 후 저장)

## 6. 정리

| 개념 | 한 줄 요약 |
|---|---|
| 텍스처 | 삼각형에 붙이는 이미지 |
| UV | 이미지 위의 0~1 주소 (DX는 v가 아래로) |
| WIC | Windows 내장 이미지 디코더 |
| SRV | 셰이더용 텍스처 읽기 허가증 (t0) |
| 샘플러 | 읽는 방법 규칙: 필터 + 주소 모드 (s0) |
| 알파 블렌딩 | 투명도로 기존 색과 섮기 (뒤부터 그리기!) |
