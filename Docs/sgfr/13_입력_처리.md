## 1. 입력의 두 가지 방식 — 폴링 vs 이벤트

02번에서 잠깐 맛보기로 나왔던 주제를 제대로 다룹니다.

### 폴링 (Polling) — "지금 눌려 있나?"를 매 프레임 묻기

```cpp
// 매 프레임 상태를 검사
if (input.IsKeyDown('W')) { 캐릭터 이동(); }
```

- 지속적인 동작에 적합: 이동, 카메라 회전, 차지 공격

### 이벤트 (Event) — "눌리는 순간" 알림받기

```cpp
// 한 번만 등록해두면 눌릴 때마다 호출됨 (jc::Event 사용!)
input.onKeyPressed.Register(1, [](int _vk) {
	printf("키 눌림: %d\n", _vk);
});
```

- 순간적인 동작에 적합: 점프, 메뉴 선택, 발사

## 2. Down / Pressed / Released — 세 가지 상태 구분

초보 때 가장 많이 헷갈리는 부분입니다. sgf의 이름 규칙:

| 함수 | 의미 | true인 기간 |
|---|---|---|
| `IsKeyDown` | 지금 눌려 있다 | 누르고 있는 내내 |
| `IsKeyPressed` | 이번 프레임에 눌리기 시작했다 | 누른 그 프레임 단 1회 |
| `IsKeyReleased` | 이번 프레임에 떼졌다 | 떼 그 프레임 단 1회 |

구현 원리는 간단합니다. **이번 프레임 상태와 지난 프레임 상태, 배열 두 개**를 비교합니다.

```
Pressed  = 이번에 눌림 && 지난번에 안 눌림
Released = 이번에 안 눌림 && 지난번에 눌림
```

그래서 매 프레임 끝에 `input.NextFrame()`을 호출해 "이번 → 지난"으로 복사해야 합니다. Application을 쓰면 자동으로 해줍니다.

## 3. 메시지에서 상태까지 — 데이터 흐름

```
Windows 메시지 (WM_KEYDOWN, WM_MOUSEMOVE, ...)
  → Window의 WndProc (02번)
  → InputManager::HandleMessage   : 상태 배열 갱신 + 이벤트 Invoke
  → 게임 코드는 IsKeyDown 등으로 조회 (폴링) 또는 등록한 콜백 수신 (이벤트)
```

연결은 단 한 줄입니다: `window.ConnectInput(&input);`

### 마우스 정보

```cpp
input.MouseX(), input.MouseY()   // 클라이언트 영역 기준 픽셀 좌표 (왼위가 0,0)
input.IsMouseDown(MouseButton::Left)
input.WheelDelta()               // 이번 프레임 휠 회전량 (120 단위)
input.onMouseMoved.Register(...) // 이벤트 방식
```

> 주의: 마우스 좌표는 **픽셀 좌표**(y가 아래로 증가)이고, 월드 좌표는 보통 y가 위로 증가합니다. 변환 공식은 14번에서 실전으로 다룹니다.

## 4. jc::Event — 이벤트 시스템의 정체

sgf의 이벤트는 jc 라이브러리의 `jc::Event`를 그대로 씁니다. (여러분이 직접 만든 코드!)

```cpp
jc::Event<int> onKeyPressed;
onKeyPressed.Register(id, 콜백);  // id로 구독ing
onKeyPressed.Unregister(id);       // 구독 해제
onKeyPressed.Invoke(vk);           // 모든 구독자 호출 (InputManager 내부에서)
```

Cocos2d-x의 EventListener와 같은 역할입니다. 구조는 훨씬 단순하지만 필요한 기능은 다 있습니다.

## 6. 정리

| 개념 | 한 줄 요약 |
|---|---|
| 폴링 | 매 프레임 상태 조회 (지속 동작용) |
| 이벤트 | 변화 순간 콜백 (순간 동작용) |
| Down/Pressed/Released | 상태/상승에지/하강에지 |
| NextFrame | 상태 배열 복사로 에지 감지 가능하게 |
| jc::Event | 구독-발행 패턴의 간단 구현 |
