# 18. 셰이딩 모델 — 람버트, 퐁, 블린-퐁: 반짝임의 공식

> 튜토리얼: `Projects/sgfr/Sources/sgfr/18_ShadingModel/`
> 선행 학습: `10_라이팅.md` (람버트 확산광)

---

## 1. 왜 필요한가요?

"셰이딩(Shading)"은 **픽셀의 최종 색을 빛과 재질로부터 계산하는 규칙**입니다. 그 규칙의 종류가 셰이딩 모델이고요.

10번에서 배운 람버트 확산광만으로는 물체가 전부 "무광 팜트 칠한 찰흑"처럼 보입니다.
현실의 사과·금속·플라스틱에는 빛이 반사되어 반짝이는 부분, 즉 **하이라이트(정반사광)**가 있습니다.
이걸 수식으로 흙내 낸 것이 퐁(Phong)과 블린-퐁(Blinn-Phong) 모델입니다. 수십 년 된 공식이지만 지금도 모바일 게임·카툴 렌더링의 기본기입니다.

---

## 2. 개념 설명 — 세 가지 빛의 합성

최종 색 = **주변광(Ambient) + 확산광(Diffuse) + 정반사광(Specular)**

### 2-1. 주변광 — "완전한 암흑은 없다"

빛이 방 안 곳곳에 튀기므로 그늘진 면도 약간은 보입니다. 이걸 복잡하게 계산하는 대신 그냥 상수로 더합니다.
우리 튜토리얼에서는 `0.15` — 즉 기본 색의 15%는 항상 보장합니다.

### 2-2. 확산광 (람버트) — 복습

면이 빛을 정면으로 받을수록 밝다: `diffuse = max(0, N · L)`
(N = 면의 법선, L = 픽셀에서 빛을 향하는 방향. 둘 다 길이 1)
표면이 거칠어서 빛을 사방으로 흩내는 재질(분필, 천)의 모험입니다. **보는 방향과 무관**하다는 게 특징입니다.

### 2-3. 정반사광 (하이라이트) — 이번 장의 주인공

거울처럼 매끈한 면은 빛을 한 방향으로 큥 반사합니다. 그 반사 방향이 **내 눈(카메라)을 향할 때만** 반짝임이 보입니다.
그래서 정반사광은 확산광과 달리 **카메라 위치에 따라 움직입니다**. (물체를 돌려보면 반짝이는 점이 미끄러지는 이유)

**퐁(Phong) 방식** — 반사 벡터를 직접 계산:
```hlsl
float3 r = reflect(-L, N);              // 빛의 반사 방향
float spec = pow(max(0, dot(r, V)), 광택지수); // V = 카메라 방향
```

**블린-퐁(Blinn-Phong) 방식** — 하프 벡터로 근사:
```hlsl
float3 h = normalize(L + V);            // 빛과 카메라의 '중간 방향'
float spec = pow(max(0, dot(N, h)), 광택지수);
```

둘의 차이: 블린-퐁이 미세하게 더 부드럽고 넓은 하이라이트를 만들며, reflect 계산이 없어 약간 저렴합니다.
그래서 실무 표준은 블린-퐁입니다. (이 튜토리얼도 시작 모드가 블린-퐁)

### 2-4. 광택 지수(Specular Power) — 재질의 매끈함

`pow(…, 지수)`의 지수가 클수록 하이라이트가 작고 날카로워집니다.

| 지수 | 느낌 |
|---|---|
| 2~8 | 무딘 플라스틱, 고무 |
| 16~64 | 광택 플라스틱, 코팅된 나무 |
| 128~256 | 금속, 거울 같은 매끈함 |

### 2-5. 자주 하는 실수 하나

확산광이 0(빛의 반대쪽 면)인데 정반사광만 반짝이면 이상합니다. 그래서 튜토리얼 셰이더는
`diffuse <= 0이면 spec = 0`으로 강제합니다. 이런 디테일이 품질을 가릅니다.

## 3. 코드 따라가기 — 18번 튜토리얼

### 3-1. UV 구(Sphere) 직접 만들기 (`GenerateSphere`)

하이라이트는 굴곡이 있어야 예쁘게 보입니다. 그래서 지구본처럼 위도(ring)×경도(segment) 격자로 구를 만듭니다.
구의 좋은 점: **법선 = 중심에서 정점 방향** 그 자체입니다. `position_ = normal_ × 반지름`으로 정점을 만들 수 있어서 코드가 짧습니다.
경도 마지막 열은 첫 열과 같은 위치지만 UV 이음새 때문에 정점을 별도로 복제합니다(주석 참고).

### 3-2. 상수 버퍼 두 개

- `CbTransform(b0)`: 월드/WVP 행렬 (매 프레임 갱신)
- `CbShading(b1)`: 빛 방향, 모드(1=퐁, 2=블린-퐁, 0=람버트만), 카메라 위치, 광택 지수, 기본 색

cbuffer는 16바이트 정렬 규칙이 있어서 C++ 구조체에서 float3 뒤에 int/float를 끼워 맞추는 방식을 썼습니다. (구조체 주석에 바이트 계산이 적혀 있으니 꼭 확인!)

### 3-3. 조작법

```
[1] 람버트만  [2] 퐁  [3] 블린-퐁
[↑/↓] 광택 지수 ×2 / ÷2 (2~256)
```

1↔2를 오가며 하이라이트 유무를, 2↔3을 오가며 하이라이트 모양 차이를, ↑↓로 재질감 변화를 관찰하세요.

## 5. 정리

- 셰이딩 = 주변광 + 확산광 + 정반사광의 합성
- 확산광은 보는 방향과 무관, 정반사광은 카메라에 따라 움직임
- 퐁 = reflect 사용, 블린-퐁 = 하프 벡터 사용(실무 표준)
- 광택 지수가 클수록 날카롭고 매끈한 재질
- diffuse가 0이면 spec도 0으로 — 디테일이 품질을 가른다

다음 장(19번)에서는 "화면이 아닌 곳에 그리기" — 모든 고급 기법의 문을 여는 렌더 타깃을 배웁니다.

## 부록: Before/After 비교 뷰

이 튜토리얼은 같은 구(구체) 두 개를 나란히 띄워 셰이딩 모델의 차이를 직접 비교할 수 있도록 되어 있습니다.

| 구분 | 위치 | 내용 |
|---|---|---|
| **Before** | 왼쪽 구 | 항상 램버트 확산광만 (기준) |
| **After** | 오른쪽 구 | 키로 선택한 셰이딩 모델 (퍼옵리지/블린-퍼옵 등) |

### 어떻게 구현했나요?

- 구 그리기를 람다 함수로 묶고 x 오프셋과 셰이딩 모드만 바꿔 두 번 그립니다.
- 왼쪽은 모드 0(램버트)으로 고정, 오른쪽만 상수 버퍼의 모드 값이 바뀝니다.
- 위/아래 방향키로 광택 지수(specular power)를 조절할 수 있습니다. (2 ~ 256)

### 관찰 포인트

- 램버트끼리 비교(1번 키)하면 양쪽이 완전히 같아집니다. 기준선이 잘 동작하는지 확인하는 용도.
- 퍼옵리지/블린-퍼옵을 선택하면 오른쪽 구에만 하이라이트(정반사 광택)가 생깁니다. 왼쪽과 비교하면 "하이라이트 = 셰이딩 모델이 추가한 성분"임이 명확합니다.
- 광택 지수를 키우면 하이라이트가 작고 날카롭게(금속 느낌), 낮추면 넓고 뻑뻑하게(플라스틱 느낌) 변합니다. 이 변화도 오른쪽에만 적용되므로 기준과 비교하며 관찰하세요.
