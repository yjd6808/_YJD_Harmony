## 1. 2D와 3D의 진짜 차이 두 가지

지금까지는 z를 거의 쓰지 않았습니다. 진짜 3D가 되려면 두 가지가 필요합니다.

1. **원근 투영**: 멀리 있는 것은 작게 보여야 한다
2. **깊이 버퍼**: 앞에 있는 것이 뒤에 있는 것을 가려야 한다

---

## 2. 원근 투영 (Perspective Projection)

08번의 직교 투영은 거리와 무관하게 같은 크기로 그립니다(2D, 설계도면용).
원근 투영은 **거리가 멀수록 작게** 그립니다. 원리는 놀랄 만큼 단순합니다.

> **x와 y를 z(거리)로 나눈다.** 2배 멀면 2배 작게. 이것이 원근법의 전부입니다.

```cpp
Mat4 proj = Mat4::PerspectiveFovLH(
	sgf::Deg2Rad(60.0f),      // fovY: 세로 시야각. 클수록 광각(어안), 작을수록 망원(줌)
	window.AspectRatio(),     // 화면 비율 (가로/세로) — 왜곡 방지
	0.1f,                     // near: 이보다 가까우면 안 그림
	100.0f);                  // far : 이보다 멀면 안 그림
```

### near/far 평면은 왜 필요한가요?

깊이 버퍼는 near~far 사이를 0~1로 압축해 기록합니다. 범위가 무한대면 압축할 수 없으니 반드시 범위를 정해야 합니다.

> 주의: `near`를 0.0001처럼 너무 작게 잡으면 깊이 정밀도가 near 근처에 몰려서 먼 물체들이 서로 깜빡이는 **z-fighting**이 생깁니다. 적당히(0.1 정도) 잡는 것이 요령입니다.

## 3. 깊이 버퍼 (Depth Buffer / Z-Buffer)

### 문제: 그리는 순서와 가림의 불일치

큐브의 뒷면을 앞면보다 나중에 그리면, 나중에 그린 뒷면이 앞면을 덮어버립니다. 매 프레임 모든 삼각형을 카메라 거리순으로 정렬하는 것은 너무 느립니다.

### 해결: 픽셀마다 거리 기록표를 둔다

깊이 버퍼는 화면과 같은 크기의 **거리 기록표**입니다. 색 버퍼가 "이 픽셀의 색"을 기록한다면, 깊이 버퍼는 "이 픽셀에 그려진 것까지의 거리"를 기록합니다.

픽셀을 그리기 직전 OM 단계에서 GPU가 자동으로 검사합니다:

```
새 픽셀의 z < 기록된 z ?  → 더 가깝다! 색과 z를 갱신
새 픽셀의 z >= 기록된 z ? → 이미 더 가까운 게 그려져 있다. 버림
```

그래서 **그리는 순서와 상관없이** 항상 가까운 것이 보입니다.

sgf에서는 이미 03번 초기화 때 깊이 버퍼를 만들어 두었고, 켜고 끄기만 하면 됩니다:

```cpp
device.SetDepthTest(true);   // 3D: 켜기 (9번, 10번)
device.SetDepthTest(false);  // 2D: 끄기 (그리는 순서 = 겹침 순서가 되게)
```

`BeginFrame`이 매 프레임 깊이 버퍼를 1(가장 멂)로 초기화합니다.

## 4. 큐브 만들기 — 왜 정점이 8개가 아니라 24개?

큐브의 기하학적 꼭짓점은 8개지만, sgf 예제는 24개(면당 4개 × 6면)를 씁니다. 왜냐하면:

- 한 꼭짓점은 3개의 면에 속합니다
- 그런데 면마다 **색(또는 법선, UV)이 다릅니다**
- 정점은 위치+색이 모두 같아야 공유할 수 있습니다

> "같은 위치라도 속성이 다르면 다른 정점" — 모델링 데이터의 중요한 상식입니다. 10번 라이팅에서는 법선 때문에 똑같이 24개가 필요합니다.

인덱스는 면당 6개 × 6면 = 36개입니다. (06번 사각형의 확장판)

## 5. 회전하는 큐브의 매 프레임 흐름

```cpp
// 1) 월드: 시간에 따라 회전 (07번 복습)
Mat4 world = Mat4::RotationY(t * 0.8f) * Mat4::RotationX(t * 0.5f);
// 2) 뷰: 카메라를 비스듬히 배치 (08번 복습)
Mat4 view = Mat4::LookAtLH(Vec3(0, 1.5f, -3.0f), Vec3(0, 0, 0), Vec3::Up());
// 3) 투영: 원근
Mat4 proj = Mat4::PerspectiveFovLH(sgf::Deg2Rad(60.0f), aspect, 0.1f, 100.0f);
// 4) 하나로 합쳐 상수 버퍼로 전송 (05번 복습)
cbData.worldViewProj_ = world * view * proj;
cb.UpdateAndBind(&device, cbData, 0);
device.Context()->DrawIndexed(36, 0, 0);
```

01번부터 배운 모든 것이 여기서 합쳐집니다!

## 7. 정리

| 개념 | 한 줄 요약 |
|---|---|
| 원근 투영 | x, y를 거리 z로 나눔 (멀수록 작게) |
| fovY | 시야각. 클수록 광각 |
| near/far | 깊이를 0~1로 압축할 거리 범위 |
| 깊이 버퍼 | 픽셀별 거리 기록표. 순서 무관하게 가림 처리 |
| 24 정점 큐브 | 면마다 속성이 다르면 정점 공유 불가 |
