# 17. 래스터라이저 스테이트 — 삼각형을 어떻게 채울지, 어느 면을 버릴지

> 튜토리얼: `Projects/sgfr/Sources/sgfr/17_RasterizerState/`
> 엔진 코드: `Projects/sgf/Sources/sgf/Graphics/GraphicDevice.h/.cpp` (`SetWireframe`, `SetCullMode`)

---

## 1. 왜 필요한가요?

04번에서 배운 렌더링 파이프라인을 떠올려 보세요: IA → VS → **RS** → PS → OM.
가운데의 **RS(Rasterizer, 래스터라이저)**는 "삼각형을 픽셀 목록으로 바꾸는" 단계입니다.
이 단계의 동작 방식을 바꾸는 객체가 **래스터라이저 스테이트**입니다. 대표 설정 두 가지:

1. **FillMode**: 삼각형 안을 채울까(Solid), 테두리 선만 그릴까(Wireframe)
2. **CullMode**: 카메라를 등진 삼각형을 버릴까 말까(컸링)

> **비유**: 상자를 생각해 보세요. 상자 뒷면은 절대 보이지 않습니다. 그런데도 뒷면 픽셀을 일일이 계산하는 건 낭비죠.
> "안 보이는 면은 아예 계산하지 말자"가 컸링입니다. 닫힌 입체 물체는 화면 픽셀의 절반을 공짜로 아끼는 셔입니다.

---

## 2. 개념 설명

### 2-1. 앞면과 뒷면을 어떻게 구분하나 — 정점 감기 방향(Winding Order)

GPU는 화면에 투영된 삼각형의 정점 순서가 **시계방향이면 앞면**, 반시계방향이면 뒷면으로 판정합니다. (DX11 기본값 기준)

우리 엔진의 모든 메시(09번 큐브, 18번 구, 21번 큐브/바닥)는 앞면이 시계방향이 되도록 인덱스를 지정했습니다.
입체 물체의 바깥면을 밖에서 보면 시계방향(앞면), 안에서 보면 반시계방향(뒷면)이 됩니다.

### 2-2. 컸 모드 세 가지

| 모드 | 버리는 면 | 결과 |
|---|---|---|
| **Back** (기본값) | 뒷면(반시계) | 정상적인 입체 물체 모습. 안 보이는 면 절약 |
| **None** | 안 버림 | 양면 모두 그림. 종이·풀·망토 같은 양면 물체용 |
| **Front** | 앞면(시계) | 물체 안쪽이 보임! 이상해 보이지만 그림자 맵 등에 일부러 쓰기도 함 |

Front 컸링은 21번 그림자 매핑에서 "피터 팬닝(그림자 여드름) 완화 기법"으로 실제로 쓰이는 테크닉입니다.

### 2-3. 와이어프레임 — 엔진 개발자의 X-ray 안경

FillMode를 Wireframe으로 바꾸면 삼각형 테두리만 그려집니다. 모델이 몇 개의 삼각형으로 이뤄졌는지,
숨겨진 면이 제대로 만들어졌는지 확인할 때 쓰는 디버깅 도구입니다. 거의 모든 상용 엔진에 있는 기능입니다.

### 2-4. DX11에서의 실체: `ID3D11RasterizerState`

```cpp
D3D11_RASTERIZER_DESC desc = {};
desc.FillMode = D3D11_FILL_SOLID;      // 또는 D3D11_FILL_WIREFRAME
desc.CullMode = D3D11_CULL_BACK;       // NONE / BACK / FRONT
desc.DepthClipEnable = TRUE;           // 근/원 평면 밖 자르기 (기본 켜짐)
device->CreateRasterizerState(&desc, &pState);
context->RSSetState(pState);
```

## 3. 엔진은 어떻게 감쌀나

```cpp
device.SetWireframe(true);            // 와이어프레임 ON
device.SetCullMode(CullMode::None);   // 컸링 끄기
device.SetCullMode(CullMode::Back);   // 기본값으로 복귀
```

내부는 (FillMode 2종) × (CullMode 3종) = 6조합을 캨시합니다. 15·16번과 완전히 같은 "상태 객체 캨시" 패턴입니다.
이제 익숙해졌죠? DX11의 상태 객체(샘플러/블렌드/래스터라이저/깊이스텐실)는 전부 이 패턴으로 다룹니다.

## 4. 코드 따라가기 — 17번 튜토리얼

회전하는 색깔 큐브 하나를 띄워놓고 상태만 바꿔가며 관찰합니다.

- **[W]**: 와이어프레임 토글 — 큐브가 삼각형 12개임이 보임
- **[1] None**: 와이어프레임 상태에서 보면 앞뒤 선이 전부 보임 (12개 삼각형 모두)
- **[2] Back**: 뒷면이 사라져 선이 줄어듦 — 이게 정상 상태
- **[3] Front**: 앞면이 사라져 물체 **안쪽**이 보임 — 속이 빈 상자를 안에서 보는 느낌

Solid 상태에서는 Back/None이 거의 구분되지 않습니다(불투명이라 어차피 앞면이 뒷면을 덮으니까).
그래서 이 튜토리얼은 와이어프레임과 함께 보는 것이 핵심입니다.

## 6. 정리

- 래스터라이저(RS)는 삼각형을 픽셀로 바꾸는 단계. 그 옵션이 래스터라이저 스테이트
- 시계방향 = 앞면. 컸링으로 안 보이는 면을 공짜로 절약 (기본은 Back)
- 와이어프레임은 메시 디버깅의 기본 도구
- 면이 안 보이면 인덱스 감기 방향부터 의심할 것

다음 장(18번)에서는 10번 라이팅을 확장해 "반짝이는 하이라이트"까지 만드는 셰이딩 모델을 배웁니다.

## 부록: Before/After 비교 뷰

이 튜토리얼은 같은 큐브 두 개를 나란히 띄워 래스터라이저 설정의 차이를 직접 비교할 수 있도록 되어 있습니다.

| 구분 | 위치 | 내용 |
|---|---|---|
| **Before** | 왼쪽 큐브 | 항상 Solid + 뒷면 컬링(Back) = 기본값 |
| **After** | 오른쪽 큐브 | 키로 선택한 채우기 모드/컬 모드 |

### 어떻게 구현했나요?

- 큐브 그리기를 람다 함수로 묶고 x 오프셋, 와이어프레임 여부, 컬 모드만 바꿔 두 번 그립니다.
- 래스터라이저 스테이트도 블렌드와 마찬가지로 "그리기 직전에 갈아끼우는 파이프라인 상태"입니다.

### 관찰 포인트

- **Wireframe**: 오른쪽만 선으로 보이므로, 왼쪽과 비교하면 삼각형 두 개가 모여 사각 면 하나를 만드는 구조가 그대로 드러납니다.
- **CullMode::None**: 격자 없이 양면을 모두 그립니다. 솔리드에서는 겨보기엔 차이가 없지만 2배로 비싸집니다. 와이어프레임으로 바꿔보면 뒷면 삼각형까지 그려지는 것이 보입니다.
- **CullMode::Front**: 앞면을 버리고 뒷면만 그립니다. 큐브 안쪽이 보이는 기묘한 모습이 되며, 왼쪽 정상 큐브와 비교하면 무엇이 잘림상태인지 명확해집니다.
- 컬링의 기준은 "삼각형의 정점 감김 방향(시계/반시계)"이라는 것을 기억하세요.
