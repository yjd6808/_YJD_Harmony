## 1. 렌더링 파이프라인이란?

GPU는 정점 데이터를 받아 픽셀 색으로 바꾸는 **공장 조립 라인**입니다.
재료(정점)가 컸베이어를 타고 여러 공정을 거쳐 완성품(픽셀 색)이 됩니다.

```
[정점 데이터] → IA → VS → RS → PS → OM → [백버퍼]
```

| 공정 | 이름 | 하는 일 | 프로그래밍 가능? |
|---|---|---|---|
| IA | Input Assembler | 정점 버퍼에서 정점을 읽어 모음 (삼각형 단위로 조립) | 설정만 가능 |
| VS | Vertex Shader | 정점 하나하나의 위치를 계산 (행렬 곱) | **○ HLSL로 직접 작성** |
| RS | Rasterizer | 삼각형 내부를 픽셀들로 쎌쎌히 분해 | 설정만 가능 |
| PS | Pixel Shader | 픽셀 하나하나의 색을 결정 | **○ HLSL로 직접 작성** |
| OM | Output Merger | 계산된 색을 백버퍼에 기록 (깊이 판정, 블렌딩) | 설정만 가능 |

> 핵심: **VS는 정점마다 한 번, PS는 픽셀마다 한 번** 실행됩니다.
> 삼각형 하나면 VS 3번, PS는 삼각형이 차지하는 픽셀 수만큼(수천~수만 번) 실행!

## 2. NDC — GPU의 표준 좌표계

VS의 최종 출력(SV_POSITION)은 **NDC(Normalized Device Coordinates)**로 해석됩니다.

```
        y=+1 (화면 위쪽)
          │
x=-1 ────┼──── x=+1
(왼쪽)    │    (오른쪽)
        y=-1 (화면 아래쪽)
```

- 해상도가 몇이든 화면 전체는 항상 x, y 각각 -1 ~ +1
- z는 0(가까움) ~ 1(멀음) — 왜 필요한지는 09번 깊이 버퍼에서
- 이번 튜토리얼은 아직 행렬을 안 배웠으므로 **NDC 좌표를 정점에 직접 적어서** 삼각형을 그립니다
- 07~09번에서 배울 행렬들은 결국 "내 좌표 → NDC" 변환기입니다

## 3. 첫 삼각형을 그리기 위해 필요한 재료 4가지

### 3-1. 정점 구조체 (VertexPC)

```cpp
// Vertex.h — Position + Color
struct VertexPC
{
	Vec3  position_;  // NDC 좌표
	Color color_;     // 정점 색
};
```

### 3-2. 정점 버퍼 (VertexBuffer)

정점 데이터는 CPU 메모리에 있으면 GPU가 못 씁니다. GPU 메모리로 복사해야 하고, 그 그릇이 정점 버퍼입니다.

```cpp
VertexBuffer vb;
vb.Create(&device, vertices, sizeof(VertexPC), 3); // 정점 3개 복사
```

### 3-3. 입력 레이아웃 (Input Layout)

GPU 입장에서 정점 버퍼는 그냥 바이트 덩어리입니다. "앞 12바이트는 POSITION(float3), 다음 16바이트는 COLOR(float4)"라고 알려주는 설명서가 입력 레이아웃입니다.
sgf에서는 각 정점 구조체가 자기 설명서를 들고 다닙니다:

```cpp
UINT layoutCount = 0;
const D3D11_INPUT_ELEMENT_DESC* pDescs = VertexPC::LayoutDescs(&layoutCount);
```

### 3-4. 셰이더 (Shader)

VS와 PS는 HLSL로 직접 작성합니다. 이번 튜토리얼의 셰이더는 아무 가공도 하지 않는 "통과(passthrough)" 셰이더입니다.

```hlsl
VSOutput VSMain(VSInput _input)
{
	VSOutput output;
	output.position = float4(_input.position, 1.0f); // 입력을 그대로 (이미 NDC니까)
	output.color = _input.color;
	return output;
}

float4 PSMain(VSOutput _input) : SV_TARGET
{
	return _input.color; // 보간된 색을 그대로
}
```

sgf의 `Shader::CompileFromString`이 내부에서 HLSL 컴파일(D3DCompile) + 입력 레이아웃 생성까지 해줍니다.

## 4. 그리기 명령 순서 (공장 가동!)

```cpp
device.BeginFrame(배경색);

vb.Bind(&device);       // IA: 이 정점 버퍼를 써라
shader.Bind(&device);   // VS/PS: 이 셰이더를 써라 (+ 입력 레이아웃)
device.Context()->IASetPrimitiveTopology(D3D11_PRIMITIVE_TOPOLOGY_TRIANGLELIST);
                        // IA: 정점 3개씩 묶어 삼각형으로 조립해라
device.Context()->Draw(3, 0);  // 정점 3개로 그려라! (공장 가동 버튼)

device.EndFrame(true);
```

### 주의: 삼각형 감기 방향 (Winding Order)

DX11은 기본적으로 **시계 방향(CW)**으로 감긴 삼각형을 앞면으로 봅니다.
반시계로 감으면 뒷면으로 취급해 그리지 않고 버립니다(백페이스 컸링). "분명히 그렸는데 안 보여요!"의 단골 원인입니다.

### 보간 (Interpolation) — 공짜로 얻는 그라데이션

세 꼭짓점에 빨강/초록/파랑을 주면 삼각형 내부가 무지개처럼 칠해집니다.
RS(래스터라이저)가 각 픽셀의 위치에 따라 세 꼭짓점 값을 섮어서 PS에 전달하기 때문입니다. 이건 색뿐 아니라 UV(11번), 법선(10번) 등 모든 VS 출력에 적용되는 규칙입니다.

## 6. 정리

| 개념 | 한 줄 요약 |
|---|---|
| 파이프라인 | 정점 → 픽셀 조립 라인 (IA-VS-RS-PS-OM) |
| NDC | 화면 전체를 -1~+1로 보는 표준 좌표 |
| 정점 버퍼 | GPU 메모리에 올린 정점 배열 |
| 입력 레이아웃 | 정점 바이트 해석 설명서 |
| VS / PS | 정점당/픽셀당 한 번씩 도는 내 코드 |
| 보간 | 꼭짓점 값을 픽셀마다 섮어주는 규칙 |
| 컸링 | 반시계 삼각형은 그리지 않음 |
