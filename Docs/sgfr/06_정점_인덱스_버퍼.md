# 06. 정점/인덱스 버퍼 — 사각형 그리기와 중복 정점 제거

> 관련 코드: `Projects/sgf/Sources/sgf/Graphics/Buffers.h/.cpp`, `Projects/sgfr/Sources/sgfr/06_VertexIndexBuffer/`
> 실행: sgfr 메뉴에서 **6번**

---

## 1. 문제 상황: 사각형을 그려보자

GPU는 삼각형만 그릴 수 있습니다. 사각형 = 삼각형 2개.

```
0 ─── 1        삼각형 A: 0, 1, 2
│ \   │        삼각형 B: 2, 1, 3
│   \ │        (둘 다 시계 방향!)
2 ─── 3
```

정점 버퍼만 쓰면 삼각형 2개 × 정점 3개 = **6개** 정점이 필요합니다.
그런데 실제 꼭짓점은 4개뿐이죠. 정점 1번과 2번이 두 번씩 중복 저장됩니다.

사각형 하나면 별거 아니지만, 캐릭터 모델은 정점이 수만 개입니다. 정점 하나는 보통 삼각형 6개에 공유되므로, 중복 저장하면 메모리가 6배가 됩니다!

---

## 2. 해결책: 인덱스 버퍼 (Index Buffer)

아이디어는 간단합니다. **정점은 중복 없이 한 번씩만 저장하고, "몇 번 정점을 써라"는 번호표를 따로 준다.**

```cpp
// 정점 4개만 저장
VertexPC vertices[4] = { /* 0:왼위, 1:오른위, 2:왼아래, 3:오른아래 */ };

// 삼각형을 만드는 번호표 6개 (시계 방향 유지!)
_u32 indices[6] = { 0, 1, 2,   2, 1, 3 };

VertexBuffer vb;
vb.Create(&device, vertices, sizeof(VertexPC), 4);

IndexBuffer ib;
ib.Create(&device, indices, 6);
```

그리기 명령도 바뀝니다:

```cpp
vb.Bind(&device);
ib.Bind(&device);                       // 번호표도 묶기
device.Context()->DrawIndexed(6, 0, 0); // Draw 대신 DrawIndexed! (인덱스 6개 사용)
```

> 비유: 정점 버퍼는 "부품 창고", 인덱스 버퍼는 "조립 설명서"입니다.
> 같은 부품(정점)을 여러 단계(삼각형)에서 재사용할 수 있습니다.

---

## 3. 정적 버퍼 vs 동적 버퍼

`Create`의 마지막 인자 `_bDynamic`이 중요합니다.

| | 정적 (기본값 false) | 동적 (true) |
|---|---|---|
| GPU 메모리 위치 | GPU 전용 (빠름) | CPU가 쓸 수 있는 곳 |
| 내용 변경 | 불가 | `Update()`로 매 프레임 가능 |
| 용도 | 지형, 건물 등 고정 모양 | 파티클, UI, 스프라이트 배치 |

```cpp
vb.Create(&device, nullptr, sizeof(VertexPC), 4, true); // 동적 생성
// 매 프레임:
vb.Update(&device, newVertices, 4); // 내용 교체 (정점 4개)
```

> 내부적으로는 `Map/Unmap`(D3D11_MAP_WRITE_DISCARD)을 씁니다. "기존 내용은 버리고 새 메모리 주세요" 방식이라 GPU가 이전 프레임을 그리는 중이어도 기다리지 않습니다. 14번 Renderer2D가 이 기법으로 스프라이트를 모아 그립니다.

## 5. 정리

| 개념 | 한 줄 요약 |
|---|---|
| 인덱스 버퍼 | 정점 재사용을 위한 번호표 |
| DrawIndexed | 번호표를 따라 그리기 |
| 사각형 | 정점 4개 + 인덱스 6개 (삼각형 2개) |
| 동적 버퍼 | 매 프레임 내용을 바꿀 수 있는 버퍼 |
| Map/Discard | GPU를 기다리게 하지 않는 쓰기 방법 |
