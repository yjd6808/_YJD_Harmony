# 10. 라이팅 — 빛으로 입체감 만들기 (람버트 확산광)

> 관련 코드: `Projects/sgf/Sources/sgf/Graphics/Vertex.h`(VertexPNT), `Projects/sgfr/Sources/sgfr/10_Lighting/`
> 실행: sgfr 메뉴에서 **10번**

---

## 1. 왜 라이팅이 필요한가요?

09번 큐브는 면마다 색을 다르게 칠해서 입체감을 냈습니다. 하지만 한 가지 색으로 칠하면? 그냥 뚜꺼운 육각형으로 보입니다.
현실에서 우리가 입체를 느끼는 이유는 **면마다 빛을 받는 양이 다르기 때문**입니다.
이 "빛을 받는 양"을 계산하는 것이 라이팅입니다.

---

## 2. 법선 (Normal) — 면이 바라보는 방향

법선은 면에 수직인 길이 1짜리 벡터입니다. "이 면은 이쪽을 보고 있어요"라는 표시입니다.

- 큐브 윗면의 법선: (0, 1, 0) — 하늘을 보고 있음
- 큐브 앞면의 법선: (0, 0, -1) — 카메라 쪽을 보고 있음

그래서 이번 튜토리얼은 정점 타입을 `VertexPNT`(Position + Normal + Texcoord)로 바꿉니다. 09번에서 배운 대로, 같은 꼭짓점이라도 면마다 법선이 다르므로 정점은 24개입니다.

---

## 3. 람버트 법칙 — 라이팅의 필수 공식

독일 과학자 람버트가 발견한 법칙: **면이 받는 빛의 양은 빛과 법선이 이루는 각도의 코사인에 비례한다.**

- 태양이 머리 바로 위 → 땅이 뜨겁다 (각도 0도, cos = 1)
- 태양이 비스듬히 → 덜 뜨겁다 (각도 60도, cos = 0.5)
- 태양이 지평선 → 빛을 못 받음 (90도, cos = 0)

그런데 01번에서 배웠죠? **단위 벡터 둘의 내적 = cos**. 그래서 코드는 단 한 줄입니다:

```hlsl
float diffuse = max(0.0f, dot(normal, -gLightDir));
```

- `-gLightDir`: 빛이 나아가는 방향을 뒤집어 "면에서 빛을 향하는 방향"으로
- `max(0, ...)`: 빛을 등진 면은 음수가 나오는데, "음의 밝기"는 없으므로 0으로 자름

### 주변광 (Ambient) — 완전한 암흑 방지

현실에서는 빛이 뱽과 바닥에 반사되어 그늘진 곳도 약간 밝습니다. 이걸 제대로 계산하는 건 너무 비싸서(전역 조명, 레이트레이싱의 영역), 그냥 상수로 대체합니다.

```hlsl
float lighting = saturate(gAmbient + diffuse); // saturate = 0~1로 자르기
float3 finalColor = gBaseColor.rgb * lighting;
```

## 4. 법선은 어떤 행렬로 변환하나요?

중요한 디테일입니다. 큐브가 회전하면 법선도 같이 회전해야 합니다.

- 위치: `mul(float4(pos, 1), gWorldViewProj)` — 이동 포함 전체 변환
- 법선: `mul(float4(normal, 0), gWorld).xyz` — **w=0**이므로 이동 무시(01번 동차 좌표!), 그리고 **월드 행렬만** 적용 (빛 계산은 월드 공간에서 하니까)

> 엄밀히는 비균등 스케일이 있으면 역전치 행렬이 필요하지만, sgf 예제는 균등 스케일만 쓰므로 월드 행렬로 충분합니다. 변환 후 `normalize()`로 길이를 다시 1로 만드는 것도 잊지 마세요.

### 상수 버퍼 2개 사용 (슬롯 분리)

10번은 변환용(b0)과 빛 정보용(b1) 상수 버퍼를 따로 씁니다. 자주 바뀌는 것(행렬)과 가끔 바뀌는 것(빛)을 분리하는 실무 패턴의 맛보기입니다.

```cpp
cbTransform.UpdateAndBind(&device, transformData, 0); // b0
cbLight.UpdateAndBind(&device, lightData, 1);         // b1
```

## 5. 튜토리얼(10번)에서 직접 확인할 것

1. 주황색 큐브가 회전하며, 빛을 받는 면은 밝고 등진 면은 어둡습니다.
2. 면이 회전하며 밝기가 부드럽게 변합니다. (cos 곡선 그대로!)
3. 위/아래 방향키로 주변광을 조절해 "암흑 속 큐브"부터 "그림자 없는 큐브"까지 체험할 수 있습니다.
4. 실험 제안: 빛 방향을 바꿔보세요. 그럴듯한 조명 연출이 의외로 쉽습니다.

## 6. 정리

| 개념 | 한 줄 요약 |
|---|---|
| 법선 | 면이 바라보는 방향 (단위 벡터) |
| 람버트 | 밝기 = max(0, dot(법선, 빛을 향한 방향)) |
| 주변광 | 간접광 대신 상수 더하기 |
| 법선 변환 | w=0으로 월드 행렬만, 후 normalize |
| 슬롯 분리 | 갱신 주기가 다른 데이터는 다른 cbuffer로 |

## 부록: Before/After 비교 뷰

이 튜토리얼은 같은 큐브 두 개를 나란히 띄워 조명의 효과를 직접 비교할 수 있도록 되어 있습니다.

| 구분 | 위치 | 내용 |
|---|---|---|
| **Before** | 왼쪽 큐브 | 조명 계산 없이 기본색 그대로 (언릿, Unlit) |
| **After** | 오른쪽 큐브 | 램버트 확산광 + 주변광 적용 |

### 어떻게 구현했나요?

- 상수 버퍼 `CbLight`에 `lit_`(int) 값을 추가했습니다. (48바이트 = 16의 배수 유지)
- 픽셀 셰이더가 `gLit == 0`이면 조명 계산을 건너뛰고 기본색을 바로 반환합니다.
- 같은 지오메트리/같은 회전을 쓰고 x 오프셋만 달리해 두 번 그립니다. 상수 버퍼만 바꿔서 같은 메시를 다른 설정으로 재활용하는 전형적인 패턴입니다.

### 관찰 포인트

- 왼쪽 큐브는 회전해도 입체감이 전혀 없습니다. 면마다 밝기 차이가 없으니 육면체가 그냥 육각형 실루엣처럼 보입니다.
- 오른쪽 큐브는 빛을 마주보는 면이 밝고 등진 면이 어둡습니다. "입체감 = 면마다 다른 밝기"라는 것을 한눈에 확인할 수 있습니다.
- 위/아래 방향키로 주변광을 조절하면 오른쪽 큐브의 그늘진 면만 밝기가 변합니다. (왼쪽은 주변광 개념 자체가 없음!)
