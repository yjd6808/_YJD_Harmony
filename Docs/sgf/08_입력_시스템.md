# 08. 입력 시스템 — InputManager가 키/마우스를 다루는 법

> 대상: `Projects/sgf/Sources/sgf/Input/InputManager.*`, `Core/Window.cpp` (WndProc)

게임 코드가 키보드/마우스를 읽는 창구는 하나입니다. `g_cInput` (InputManager).
입력에는 **폴링(지금 상태 묻기)** 과 **이벤트(순간 콜백)** 두 방식이 있고, 이 클래스는 둘 다 지원합니다.

---

## 1. 입력은 어떻게 들어오나요? (메시지 → 상태)

```
OS가 키/마우스 이벤트를 윈도우에 전달
  └─▶ Window::WndProc (Window.cpp:240) — WM_KEYDOWN, WM_LBUTTONDOWN, WM_MOUSEWHEEL 등
        └─▶ g_cInput.HandleMessage(msg, wParam, lParam)   ← InputManager.cpp
              ├─ 키 상태 배열 갱신 (keyDown_[256])
              ├─ 마우스 버튼/좌표/휠 갱신
              └─ 이벤트 발행 (onKeyPressed 등)
매 프레임 끝 ──▶ g_cInput.NextFrame()     ← InputManager.cpp:122
              └─ 현재 상태를 "이전 프레임"으로 복사 (Pressed/Released 판정의 비밀)
```

**핵심 원리**: `IsKeyPressed`는 "이번 프레임에 눌렸나?" = `keyDown && !prevKeyDown` 입니다.
그래서 매 프레임 끝에 `NextFrame()`이 "지금 상태"를 "이전 상태"로 밀어넣어야 합니다.
(메인 루프의 ③번 — `Application::Run`이 자동으로 호출합니다)

---

## 2. 폴링 API — "지금 눌려 있나?" 매 프레임 묻기

이동 같은 **지속 동작**에 적합합니다. `OnUpdate`에서 매 프레임 직접 확인합니다.

| API | 의미 |
|---|---|
| `IsKeyDown(VK_LEFT)` | 누르고 있는 내내 true |
| `IsKeyPressed(VK_SPACE)` | 누른 **순간 한 프레임**만 true |
| `IsKeyReleased(VK_SPACE)` | 뗀 **순간 한 프레임**만 true |
| `IsMouseDown(jc::MouseButton::Left)` | 버튼 누르고 있는 내내 true |
| `IsMousePressed/Released(button)` | 클릭/릴리스 순간 한 프레임 |
| `MouseX() / MouseY()` | 커서 좌표 (클라이언트 영역, 좌상단 원점, 픽셀) |
| `WheelDelta()` | 이번 프레임 휠 이동량 (+위로 / -아래로 / 0) |

> 키코드는 Win32 가상 키코드(`VK_*`)를 그대로 사용합니다. 버튼 번호는 `jc::MouseButton` 열거형 (`Left=0, Right=1, Middle=2`).

---

## 3. 이벤트 API — "눌리는 순간" 콜백 받기

점프/공격 같은 **1회성 동작**에 적합합니다 (Cocos2d-x EventListener와 같은 역할).
`jc::Event` 기반 — `+=`로 구독, 등록 시점과 무관하게 발생합니다.

| 이벤트 | 인자 | 의미 |
|---|---|---|
| `onKeyPressed` | `_s32 vk` | 키가 눌린 순간 |
| `onKeyReleased` | `_s32 vk` | 키가 떨어진 순간 |
| `onMousePressed` | `(button, x, y)` | 버튼이 눌린 순간 |
| `onMouseReleased` | `(button, x, y)` | 버튼이 떨어진 순간 |
| `onMouseMoved` | `(x, y)` | 커서가 움직인 순간 |
| `onMouseWheel` | `_s32 delta` | 휠이 굴러간 순간 |

```cpp
g_cInput.onKeyPressed += [](_s32 _vk)
{
	if (_vk == VK_SPACE) { /* 점프! */ }
};
```

## 4. 폴링 vs 이벤트 — 언제 뭘 쓰나

| | 폴링 (IsKeyDown 등) | 이벤트 (onKeyPressed 등) |
|---|---|---|
| 타이밍 | 매 프레임 상태 확인 | 발생 순간 1회 |
| 상태 보존 | 다음 프레임에 사라짐 | 발생 후 사라짐 (유지하려면 직접 저장) |
| 어울리는 곳 | 이동/회전/연속 조작 | 점프/공격/메뉴/1회성 |
| 구현 | `OnUpdate`에서 조건문 | 콜백 등록 (생성자/OnEnter에서) |

> **현실 가이드**: "누르는 동안"은 폴링, "눌렀을 때 딱 한 번"은 둘 다 가능하지만
> 폴링(`IsKeyPressed`)이 코드 흐름이 단순해 보통 먼저 씁니다. 이벤트는 전역 단축키처럼
> "어느 씬에서든 반응해야 하는 입력"에 유리합니다.

## 5. 카메라와의 협력 — DriveDefault*

표준 카메라 조작은 이미 만들어져 있습니다. `g_cInput`을 넘기기만 하면 됩니다.

| 함수 | 조작 |
|---|---|
| `Camera2D::DriveDefault2D(g_cInput, dt)` | 방향키 이동 + 휠 줌 |
| `Camera3D::DriveDefault3D(g_cInput, dt)` | WASD 이동 + 드래그 궤도 + 휠 줌 |

내부적으로 폴링(`IsKeyDown`)과 마우스 좌표/휠을 사용합니다.
자세한 사용은 `04_씬_시스템과_카메라.md`의 카메라 섹션을 참고하세요.

---

## 6. 요약 — 기억할 다섯 문장

1. 입력은 `WndProc → HandleMessage → 상태 배열` 순으로 들어오고, `NextFrame()`이 매 프레임 상태를 밀어넣는다.
2. 폴링은 "지금 상태"를 묻는 것 (이동/연속), 이벤트는 "순간"을 받는 것 (1회성).
3. `IsKeyPressed` = "이번 프레임에 막 눌렸나" — 이전/현재 상태 비교 덕분에 가능하다.
4. 마우스 좌표는 클라이언트 픽셀 좌표 (좌상단 원점) — 월드 좌표 변환은 `Camera2D::ScreenToWorld2D`.
5. 카메라 표준 조작은 `DriveDefault2D/3D(g_cInput, dt)` 한 줄로 끝난다.
