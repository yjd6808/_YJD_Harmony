# 06. 예제 코드 모음 — 복사해서 바로 돌려보는 9가지 패턴

> **이 문서 하나로**: sgf의 핵심 사용 패턴 9가지를 완성된 코드로 익힙니다. 각 예제는 "무엇을 배우나 → 코드 → 짚어볼 포인트" 순서로 구성되어 있습니다. 순서대로 따라하면 2D 도형부터 3D 카메라, 씬 전환, 리소스, 입력까지 한 바퀴 돌게 됩니다.
>
> 개념 설명이 필요하면: 부팅 01 / 2D 02 / 3D 03 / 씬 04 / 리소스 05 / 입력 08

---

## 예제 1. 가장 작은 실행 프로그램 — 빈 씬 하나

**배우는 것**: 앱 시작 → 첫 씬 진입의 최소 골격. 모든 예제의 베이스입니다.

```cpp
#include <sgf.h>

class MyScene : public Scene2D
{
public:
	void OnEnter() override
	{
		GetCamera2D()->SetOrthographic2D(1280, 720);   // 좌상단 원점, 픽셀 좌표
	}
};

class MyApp : public sgf::Application
{
public:
	void ApplicationDidFinishLaunching() override
	{
		g_cDirector.RunScene(dbg_new MyScene());       // 첫 씬은 반드시 여기서
	}
};

int WINAPI wWinMain(HINSTANCE, HINSTANCE, LPWSTR, int)
{
	MyApp app;
	if (app.Initialize(L"내 게임", 1280, 720))
	{
		app.Run();
	}
	app.Finalize();
	return 0;
}
```

**포인트**
- 첫 씬은 생성자가 아니라 `ApplicationDidFinishLaunching`에서 띄웁니다. (그 전엔 디바이스/리소스가 없음 — 01장)
- `Initialize → Run → Finalize` 세 줄이 앱 수명 전체입니다.
- `dbg_new`는 디버그 빌드에서 메모리 누수 추적이 되는 new입니다. 씬/오브젝트 생성은 항상 이걸로.

## 예제 2. 스태틱 도형 선언 — 움직이지 않는 것들

**배우는 것**: "OnEnter에서 1회 선언(bake) → OnRender에서 id로 예약"이라는 스태틱 경로의 기본형. (원리는 02장)

```cpp
class MyScene : public Scene2D
{
	_u32 floorId_ = 0;
	_u32 boxId_ = 0;
	_u32 circleId_ = 0;

public:
	void OnEnter() override
	{
		GetCamera2D()->SetOrthographic2D(1280, 720);

		// 선언 = 버텍스 1회 구워 캐시 (재계산 없음)
		floorId_  = DeclareStaticRect(rect(0, 620, 1280, 100), color(40, 40, 60));
		boxId_    = DeclareStaticRect(rect(100, 200, 80, 80), color(255, 200, 0));
		circleId_ = DeclareStaticCircle(vec2(600, 400), 50, color(100, 200, 255), 32);
	}

	void OnRender() override
	{
		RenderStatic(floorId_);     // 매 프레임: 캐시 참조 예약만
		RenderStatic(boxId_);
		RenderStatic(circleId_);
	}
};
```

**포인트**
- 선언은 OnEnter, 예약은 OnRender. 위치가 바뀌지 않는 UI/배경에 최적.
- 단색 도형은 전부 흰 텍스처 배치 하나로 합쳐짐 → 이 씬의 도형 전부가 DrawCall 1번.

## 예제 3. Shape2D 노드 — 선언·예약을 노드에 맡기기

**배우는 것**: 스태틱 2단계가 귀찮을 때 쓰는 편의 노드. AddChild만 하면 끝.

```cpp
void OnEnter() override
{
	GetCamera2D()->SetOrthographic2D(1280, 720);

	Shape2D* pPanel = dbg_new Shape2D("panel");
	pPanel->SetRect(rect(20, 20, 300, 150), color(30, 30, 30, 200));
	AddChild(pPanel, 0);            // 붙는 순간 1회 bake, 이후 자동 드로우

	Shape2D* pBorder = dbg_new Shape2D("border");
	pBorder->SetRectOutline(rect(20, 20, 300, 150), 2.0f, color(255, 255, 255));
	AddChild(pBorder, 1);           // zOrder 1 → 패널 위에
}
```

**포인트**
- OnRender 재정의 없이 도형이 그려집니다. Shape2D가 내부에서 선언/예약을 대신합니다.
- 단, **절대좌표 1회 bake**라 이후 Transform 이동이 반영되지 않습니다. 움직일 것은 예제 4로.

## 예제 4. 움직이는 도형 — 메시 + Transform

**배우는 것**: 움직이는 것의 정답 경로. 버텍스는 공용 단위 메시 그대로, 위치만 Transform으로. (원리는 02장 5절)

```cpp
class Spinner : public GameObject
{
public:
	Spinner() : GameObject("spinner")
	{
		SetMesh((Mesh*)g_cResourceMgr.Find(
			g_cResourceMgr.GetPrimitiveMesh2DKey(PrimitiveMesh2DType::Rect)));
		GetMaterial()->SetBaseColor(color(255, 100, 100));
		GetTransform()->SetLocalScale(vec3(120, 120, 1));      // 단위 메시 → 120px
		GetTransform()->SetLocalPosition(vec3(640, 360, 0));
	}

	void OnUpdate(const jc::TimeSpan& _dt) override
	{
		const _f32 dt = (_f32)_dt.TotalSeconds();
		angle_ += jc_math_deg2rad(90.0f) * dt;                 // 초당 90도
		GetTransform()->SetRotation2D(angle_);
	}

private:
	_f32 angle_ = 0.0f;
};

// 씬쪽: AddChild(dbg_new Spinner(), 10);  — 이게 전부
```

**포인트**
- `각도 += 속도 * dt` — 프레임레이트와 무관하게 초당 90도. (dt의 의미는 01장 타이머 절)
- 버텍스는 한 번도 재계산되지 않습니다. 월드 행렬(b1)만 바뀝니다.
- OnRender 재정의가 없음에 주목 — 메시가 설정된 GameObject는 자동으로 그려집니다.

## 예제 5. 트리와 펴링 이동 — 부모를 따라다니는 자식

**배우는 것**: 부모-자식 Transform 상속 + 키보드 펴링 이동.

```cpp
class Chick : public GameObject   // 병아리: 부모(닭)를 따라다닌다
{
public:
	Chick() : GameObject("chick")
	{
		SetMesh((Mesh*)g_cResourceMgr.Find(
			g_cResourceMgr.GetPrimitiveMesh2DKey(PrimitiveMesh2DType::Circle)));
		GetMaterial()->SetBaseColor(color(255, 230, 100));
		GetTransform()->SetLocalScale(vec3(30, 30, 1));
		GetTransform()->SetLocalPosition(vec3(-60, 0, 0));   // 부모 기준 왼쪽 60px
	}
};

class Hen : public GameObject     // 닭: 화살표 키로 이동
{
public:
	Hen() : GameObject("hen")
	{
		SetMesh((Mesh*)g_cResourceMgr.Find(
			g_cResourceMgr.GetPrimitiveMesh2DKey(PrimitiveMesh2DType::Circle)));
		GetMaterial()->SetBaseColor(color(255, 255, 255));
		GetTransform()->SetLocalScale(vec3(60, 60, 1));
		GetTransform()->SetLocalPosition(vec3(640, 360, 0));
		AddChild(dbg_new Chick(), 0);                        // 자식으로 붙이기
	}

	void OnUpdate(const jc::TimeSpan& _dt) override
	{
		const _f32 dt = (_f32)_dt.TotalSeconds();
		vec3 pos = GetTransform()->GetLocalPosition();
		if (g_cInput.IsKeyDown(VK_RIGHT)) pos.x_ += 200.0f * dt;   // 펴링: 매 프레임 상태 확인
		if (g_cInput.IsKeyDown(VK_LEFT))  pos.x_ -= 200.0f * dt;
		if (g_cInput.IsKeyDown(VK_DOWN))  pos.y_ += 200.0f * dt;   // 2D는 y가 아래로 증가
		if (g_cInput.IsKeyDown(VK_UP))    pos.y_ -= 200.0f * dt;
		GetTransform()->SetLocalPosition(pos);
	}
};
```

**포인트**
- 병아리는 이동 코드가 한 줄도 없지만 닭을 따라다닙니다 — 자식의 월드 행렬은 부모 × 로컬이기 때문(04장 Transform).
- `IsKeyDown`은 "지금 눌려 있는가"(이동에 적합), `IsKeyPressed`는 "이번 프레임에 막 눌렸는가"(점프/메뉴에 적합). 구분은 08장.

## 예제 6. 3D 큐브와 카메라 — 첫 3D 씬

**배우는 것**: Scene3D + 메시/머티리얼/월드 행렬로 그리기 + 디버그 그리드. (원리는 03장)

```cpp
class CubeScene : public Scene3D
{
public:
	void OnEnter() override
	{
		GetCamera3D()->SetLookAt(vec3(3, 2, -3), vec3(0, 0, 0), vec3(0, 1, 0));
		GetCamera3D()->SetPerspectiveDegrees(60.0f, 1280.0f / 720.0f, 0.1f, 100.0f);
	}

	void OnUpdate(const jc::TimeSpan& _dt) override
	{
		GetCamera3D()->DriveDefault3D(_dt);   // 우클릭 회전 + WASD 이동 (디버그용)
		angle_ += (_f32)_dt.TotalSeconds();
	}

	void OnRender() override
	{
		Mesh* pCube = (Mesh*)g_cResourceMgr.Find(
			g_cResourceMgr.GetPrimitiveMesh3DKey(PrimitiveMesh3DType::Cube));
		Material* pMat = g_cResourceMgr.GetDefaultMaterial3D();

		mat4 world = mat4::CreateScale(1.0f) * mat4::CreateRotationY(angle_)
		           * mat4::CreateTranslation(0, 0.5f, 0);
		DrawMesh(pCube, pMat, world);

		g_cRenderer3D.DrawGrid(10, 1.0f, color(60, 60, 80));   // 바닥 격자
		g_cRenderer3D.DrawAxis(2.0f);                          // XYZ 축
	}

private:
	_f32 angle_ = 0.0f;
};
```

**포인트**
- world = S × R × T 순서(왼쪽부터 적용). 순서를 바꾸면 결과가 달라집니다(03장).
- 그리드/축은 VertexPC 디버그 배치로 별도 DrawCall 통에 모입니다.
- `DriveDefault3D` 한 줄로 씬을 둘러볼 수 있습니다. 실제 게임 카메라는 직접 작성.

## 예제 7. 씬 전환과 서브 윈도우

**배우는 것**: ReplaceScene의 안전한 사용법 + 별도 창에 다른 씬 띄우기. (원리는 04장)

```cpp
// 씬 전환: 키 입력 순간 요청만 기록되고, 다음 프레임 경계에서 교체된다
void TitleScene::OnUpdate(const jc::TimeSpan& _dt)
{
	if (g_cInput.IsKeyPressed(VK_RETURN))
	{
		g_cDirector.ReplaceScene(dbg_new BattleScene());   // 이번 프레임은 계속 TitleScene
	}
}

// 서브 윈도우: 창 하나 더 만들고 다른 씬을 돌린다
void MyApp::ApplicationDidFinishLaunching()
{
	g_cDirector.RunScene(dbg_new GameScene());

	Window* pSub = CreateSubWindow(L"미니맵", 400, 300);
	g_cDirector.RunScene(dbg_new MiniMapScene(), pSub);    // 윈도우별 씬 슬롯
}
```

**포인트**
- ReplaceScene 직후에도 현재 프레임은 이전 씬이 마저 실행됩니다. "즉시 교체"가 아님을 기억하세요(자기 발밑 사다리 보호).
- 서브 윈도우는 각자 스왑체인/깊이버퍼를 소유하며(01장), 메인 루프가 창별로 BeginFrame→Render→Present를 돌려줍니다.
- 사용자가 서브 창을 닫으면 다음 프레임 그리기 전에 자동 정리됩니다.

## 예제 8. 텍스처 로드와 머티리얼 — 스프라이트 띄우기

**배우는 것**: 파일 → 키 → 머티리얼 → 오브젝트로 이어지는 리소스 파이프라인. (원리는 05장)

```cpp
void OnEnter() override
{
	GetCamera2D()->SetOrthographic2D(1280, 720);

	// 1. 로드 → 키 (중복 경로면 기존 키 재사용)
	_u32 texKey = g_cResourceMgr.LoadTextureFromFile("Assets/player.png");

	// 2. 머티리얼에 키로 연결 (포인터 보관 안 함 — D-13)
	Material* pMat = g_cResourceMgr.CreateMaterial2D();
	pMat->SetTextureKey(0, texKey);

	// 3. 공용 Rect 메시 + 머티리얼 + 크기
	GameObject* pSprite = dbg_new GameObject("player");
	pSprite->SetMesh((Mesh*)g_cResourceMgr.Find(
		g_cResourceMgr.GetPrimitiveMesh2DKey(PrimitiveMesh2DType::Rect)));
	pSprite->SetMaterial(pMat);
	pSprite->GetTransform()->SetLocalScale(vec3(128, 128, 1));
	pSprite->GetTransform()->SetLocalPosition(vec3(640, 360, 0));
	AddChild(pSprite, 10);
}
```

**포인트**
- 머티리얼에 들어가는 것은 포인터가 아니라 **키**입니다. 바인드 순간에만 Find로 실체를 찾습니다.
- 같은 텍스처 키를 쓰는 스프라이트들은 자동으로 한 배치에 묶입니다(02장 배칭).

## 예제 9. 입력 두 가지 방식 — 펴링과 이벤트

**배우는 것**: 같은 입력을 "매 프레임 묻기(펴링)"와 "일어날 때 받기(이벤트)" 두 스타일로 처리하기. (원리는 08장)

```cpp
// 방법 1: 펴링 — 이동처럼 "지속 상태"가 필요할 때
void OnUpdate(const jc::TimeSpan& _dt) override
{
	if (g_cInput.IsKeyDown('A'))            { /* 누르고 있는 동안 계속 */ }
	if (g_cInput.IsKeyPressed(VK_SPACE))    { /* 누른 그 프레임에 1회 */ }
	if (g_cInput.IsMouseButtonPressed(MouseButton::Left))
	{
		vec2 pos = g_cInput.GetMousePosition();   // 클라이언트 좌표
	}
}

// 방법 2: 이벤트 — 버튼 클릭처럼 "순간"을 구독할 때
void OnEnter() override
{
	g_cInput.OnKeyDown += [this](_u32 vk)
	{
		if (vk == VK_ESCAPE) { g_cDirector.ReplaceScene(dbg_new TitleScene()); }
	};
	g_cInput.OnMouseDown += [this](MouseButton btn, const vec2& pos)
	{
		/* 클릭 위치로 UI 판정 등 */
	};
}
```

**포인트**
- 펴링은 "매 프레임 확인하는 지속 동작"(이동), 이벤트는 "발생 순간의 단발 반응"(클릭/단축키)에 어울립니다.
- IsKeyPressed(막 눌림)의 판정 기준은 "직전 프레임 스냅숏과의 비교"이며, 그 스냅숏은 메인 루프 끝의 NextFrame이 찍습니다(01장·08장).
