# 04. 씬 시스템과 카메라 — 게임을 담는 그릇

> 대상: `Projects/sgf/Sources/sgf/Scene/` 전부

게임 코드가 실제로 살아있는 곳입니다. 씬(Scene)이 게임을 담고, 게임 오브젝트(GameObject)가 트리를 이루고,
디렉터(Director)가 씬을 갈아끼우고, 카메라가 세상을 바라봅니다.

---

## 1. Scene — 씬의 뼈대

`Scene.h` — 추상 베이스. 하는 일은 4가지입니다.

```
Scene (추상)
├─ ① 트리: root_ (GameObject "Root") 를 소유 — 모든 게임 오브젝트의 부모
├─ ② 카메라: defaultCamera_ / selectedCamera_ 관리
├─ ③ 예약 창구 (가상): RenderStatic / RenderDynamic / DrawMesh — 파생이 구현
└─ ④ 데이터 보관: DataMap (씬 전역 임시 데이터)
```

| 함수 | 위치 | 설명 |
|---|---|---|
| `CreateDefaultCamera(Camera*)` | `Scene.cpp:39` | 기본 카메라 지정 (파괴 소유권 가짐) |
| `SelectCamera(GameObject*)` | `Scene.cpp:49` | 그릴 때 쓸 카메라 선택 |
| `SelectDefaultCamera()` | `Scene.cpp:61` | 기본 카메라로 복귀 |
| `AddChild(go, zOrder)` | `Scene.cpp:67` | root_ 트리에 추가 (씬 소속 전파 + OnEnter) |
| `RemoveChild(go)` | `Scene.cpp:81` | 트리에서 분리 (OnExit) |
| `RenderNode(go)` | `Scene.cpp:100` | 트리 순회 (파생 RenderScene이 호출) |
| `SetWindow/SetDevice` | `Scene.cpp:115/121` | 소속 창/디바이스 주입 (Director가 호출) |

> **AddChild는 running 중인 씬에서만 가능**합니다. (씬이 아닌 곳에서 씬 예약 창구를 쓰는 실수 방지)

### Scene2D vs Scene3D

| | Scene2D | Scene3D |
|---|---|---|
| 예약 창구 | DeclareStatic 선언들 + RenderStatic/RenderDynamic | DrawMesh |
| 기본 카메라 | Camera2D (직교) | Camera3D (원근) |
| 그리는 곳 | Renderer2D | Renderer3D |
| 메시 자동 드로우 | 가능 (Scene2D::DrawMesh — Scene2D.cpp:104) | 가능 |

## 2. GameObject — 씬 트리의 노드

`GameObject.h` — 4가지 일을 합니다.

```
GameObject
├─ ① 고유 ID (GID): IdProvider가 순수 증가 발급 — 소멸 시 반환 (키 재사용 없음)
├─ ② 트리: AddChild/RemoveChild + zOrder 정렬 삽입
├─ ③ 렌더 훅: OnRender() — 파생이 그리기 구현
└─ ④ 수명주기 훅: OnEnter/OnExit — 씬 소속 확정/해제 시 1회 호출
```

| 함수 | 위치 | 설명 |
|---|---|---|
| `AddChild(child, zOrder)` | `GameObject.cpp:59` | zOrder 오름차순으로 정렬 삽입 (z가 작을수록 아래) |
| `RemoveChild(child)` | `GameObject.cpp:79` | 트리 분리 (OnExit 1회) |
| `SetZOrder(z)` | `GameObject.cpp:116` | 순서 변경 (정렬 다시) |
| `SetMesh(Mesh*)` | `GameObject.cpp:151` | 2D/3D 메시 자동 드로우 등록 |
| `SetVisible(bool)` | `GameObject.cpp:157` | 트래버설에서 제외/포함 |
| `RenderSelf()` | `GameObject.cpp:165` | 트래버설 중 호출되는 렌더 훅 |
| `Update(dt)` | `GameObject.cpp:193` | (씬이 호출) 매 프레임 갱신 훅 |
| `Initialize(device)` | `GameObject.cpp:175` | 장치 필요 리소스 1회 준비 |
| `SetScene(scene)` | `GameObject.cpp:204` | 씬 소속 설정 (자식에게 전파) |

**기본 컴포넌트**: 모든 GameObject는 `Transform`과 `Material`을 기본으로 가집니다.
(`Component.h` — `ctTransform=0`, `ctMaterial=1` 예약, `ctCustom=100`부터 사용자 정의)

**자동 드로우 흐름**:
```
GameObject::SetMesh(mesh)  →  RenderScene의 트리 순회가 RenderSelf() 호출
                                    └─▶ Scene::RenderNode가 mesh 노드면 DrawMesh 예약 (메시 자동 드로우)
                                          ├─ 3D 메시 → Renderer3D (Scene3D)
                                          └─ 2D 프리미티브 메시 → Renderer2D 배칭 (Scene2D — vfPTC2D)
```

> **메시 자동 드로우 = "움직이는 도형"의 정석**: `AddChild` + `SetMesh(2D 프리미티브 메시)` + `SetLocalPosition`만 하면
> 월드 행렬(부모 변환 포함)이 Transform에서 계산되어 매 프레임 자동으로 그려집니다. 그리기 코드가 필요 없습니다.
> (Scene2D::DrawMesh — Scene2D.cpp:104 → Renderer2D::DrawMesh 배칭)

## 3. Shape2D — 2D 프리미티브 자동 드로우 편의 노드

`Shape2D.h/.cpp` — **가만히 있는 2D 도형**을 위한 편의 노드입니다. `Scene2D`에서만 동작합니다.

```
Shape2D : GameObject  (Scene2D 전용)
├─ SetRect / SetCircle / SetLine / SetTriangle (AddChild 전에 설정)
├─ AddChild(pShape, zOrder) ──▶ OnEnter 1회: DeclareStaticXX로 bake → staticId_
├─ 매 프레임 ──▶ OnRender: RenderStatic(staticId_) 자동 예약 (그리기 코드 불필요)
└─ RemoveChild ──▶ OnExit: staticId_ 무효화 (staticCache는 순수 증가 — 반납 없음)
```

| 함수 | 위치 | 설명 |
|---|---|---|
| `SetRect(region, color)` | `Shape2D.cpp:23` | 사각형 |
| `SetCircle(center, radius, color, segments)` | `Shape2D.cpp:31` | 원 |
| `SetLine(p1, p2, thickness, color)` | `Shape2D.cpp:41` | 선분 |
| `SetTriangle(p1, p2, p3, color)` | `Shape2D.cpp:51` | 삼각형 |

**언제 쓰나**: UI 패널/테두리/HP바 배경처럼 **절대좌표로 고정된** 도형에 적합합니다.
완전 정적(1회 bake)이라 빠르고 코드가 짧습니다.

**언제 안 쓰나**: 움직이는 도형은 `SetMesh(2D 프리미티브 메시)` + Transform 이동을 쓰세요 (메시 자동 드로우 경로).
런타임에 모양이 바뀌는 채움(게이지 등)은 `RenderDynamic`이 맞습니다.

`Transform.h/.cpp` — 로컬(부모 기준) 값 저장 + 월드 행렬 캐시.

**Dirty 플래그 전파**: 값을 바꾸면 `SetDirty()` — `Transform.cpp:113` 가 자신과 자식 전체에
"월드 행렬이 낡았다"를 표시합니다. 월드 행렬을 요청하면 그때 다시 계산합니다 (lazy).
자식 월드 = 자식 로컬 × 부모 월드 (계층 변환).

## 7. 씬 수명주기 (OnEnter → OnUpdate → OnRender → OnExit)

```
Director::RunScene / ReplaceScene
  └─▶ 씬 시작 ──▶ root_ 트리 AddChild 시 OnEnter 1회 (스태틱 bake 등)
  매 프레임 ──▶ Director::Update → 씬의 OnUpdate(dt) + 트리 Update
  매 프레임 ──▶ Director::Render → 씬의 RenderScene (트리 순회 + OnRender)
  씬 교체  ──▶ 기존 씬 정리 → 트리 정리 → 각 노드 OnExit 1회
```

> **비유**: 씬은 연극 무대, GameObject는 배우, Director는 무대 감독, 카메라는 관객의 눈.

---

## 8. 요약 — 기억할 다섯 문장

1. 씬 = root_ 트리 + 카메라 + 예약 창구. 게임 코드는 씬에만 접근한다.
2. GameObject = ID + 트리 + 훅(OnEnter/OnExit/OnRender). 기본 컴포넌트는 Transform/Material.
3. 가만히 있는 2D 도형은 `Shape2D`, 움직이는 도형은 `SetMesh` + Transform (메시 자동 드로우).
4. Transform 변경은 dirty를 자식까지 전파하고 월드 행렬은 요청 시 재계산한다.
5. 카메라도 GameObject다. Camera2D/3D의 `DriveDefault*` 한 줄이면 표준 조작이 끝난다.
